# World V1 — useful places and professional presentation

F7 retains the accepted Canvas renderer and existing native function identities.
The qualified F6 host stays frozen while this work uses another isolated host.

The function catalogue gains native localized search and place grouping, including
direct access to ordinary application destinations. Tools without a separate native
screen remain explicit actions through the ordinary LIA composer, with native HITL;
opening a place never runs a tool. Keyboard interaction and visible affordances
share one owner-scoped action, and global access remains available without walking.

Atmosphere reads only the existing cached companion weather and native timezone,
with a server clock anchor. It receives no location and makes no provider or model
request. Missing/stale weather is neutral, reduced-motion removes particles, and
lighting must preserve navigation readability. Owner changes clear the context.

Peer representations use a bounded native accepted-connection directory, private to
the caller, with mutual blocks, active-account filtering and no email/profile/home
data. Eligible visible live avatars suppress their duplicate proxy. Existing LIA
has no reliable, consented application-wide online lease: session lifetime and the
habits learning-presence marker are not evidence of being online. Unknown presence
must be labelled unknown, not falsely called offline/asleep or at a live computer.
Neutral private vignettes and an explicit ordinary LIA relay composition are used
until a real presence source is introduced. No new learning signal is written.

Presentation keeps the scene spacious: bounded zoom, follow/free camera, minimap,
compact non-overlapping controls, readable names and stable material/detail scale.
Phone portrait and short landscape keep every essential action reachable, preserve
drafts/IME and use native accessible dialogs. Decorative art changes no collision
footprint. Authored asset/layout catalogues remain separate from owner data.

Qualification covers localized search/native no-send, contacts with many accepted
peers, block/deletion/live-duplicate filters, cached-weather expiry and owner change,
keyboard/pointer/touch, reduced motion, screenshot review and browser performance.
Physical Pi/phone thermals and real translation fidelity remain distinct release
evidence; browser emulation cannot establish them.

The optimization choices follow [MDN Canvas guidance](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API/Tutorial/Optimizing_canvas)
on cached repeated drawing and [requestAnimationFrame timing](https://developer.mozilla.org/en-US/docs/Web/API/Window/requestAnimationFrame)
on elapsed-time animation. Actual cadence/cost is measured rather than inferred
from those techniques.
