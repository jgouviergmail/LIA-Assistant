# UXR Lot 10 — B12: skills gallery + install-from-URL + declarative channels

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline
> execution — program mandate forbids subagents). Steps use checkbox syntax.

**Goal:** Skills gallery UI (detail modal, provenance warning, preview image), a
declarative `channels:` frontmatter field, and `POST /skills/import-from-url` that
feeds the existing hardened `SkillImportService.import_upload` pipeline unchanged.

**Architecture:** Backend adds one pure module (`url_import.py`) that REUSES the
existing SSRF validator (`agents/web_fetch/url_validator.validate_url` — scheme,
hostname blacklist, DNS-resolve + blocked ranges incl. IPv4-mapped IPv6) with a
stricter https-only pre-check, streams the body under a settings cap, then hands
bytes to the untouched import pipeline. Frontend refactors `SkillsSettings` into a
thin shell + `SkillGallery`/`SkillDetailModal`/`ImportFromUrlDialog` (CC budgets).

**Tech Stack:** FastAPI + httpx (already pinned), Pydantic settings, vitest + RTL.

## Global Constraints

- Systemic Rules (CLAUDE.md): settings-driven values (never hardcoded), i18n ×6
  strict parity, structlog, no PII at INFO, ToolResponse n/a (routes), SLOC caps,
  CC <15 per new function, shrink-only ratchets, no `Any`/casts.
- Sandbox invariants byte-untouched (CSP, iframe airlock, srcDoc).
- `SkillImportService.import_upload` is called with EXACTLY the same semantics as
  the upload path (zero bypass; S1–S4 + 409 conflicts apply verbatim).

### Task 3: `skills/url_import.py` — hardened fetch (pure, no route logic)

**Files:** Create `apps/api/src/domains/skills/url_import.py`; test
`tests/unit/domains/skills/test_url_import.py`.
**Interfaces:** `async def fetch_skill_from_url(url: str) -> tuple[bytes, str]`
(bytes, inferred filename). Raises `SkillImportError` (existing exceptions module)
with stable codes: `url_not_https`, `url_blocked`, `url_fetch_failed`,
`url_too_large`, `url_not_skill_content`.
**Hardening:** https-only pre-check → `validate_url()` (reused SSRF validator) →
httpx `follow_redirects=False`, `timeout=settings`, **streamed** read capped at
`max_bytes` (abort mid-stream) ; 3xx response ⇒ error (redirects are refusals, not
follows); filename from URL basename, fallback by magic bytes (`PK\x03\x04` ⇒ .zip,
else SKILL.md when content starts with `---`); anything else ⇒ `url_not_skill_content`.

- [ ] Failing tests: SSRF matrix (`http://` refused pre-validator, `https://127.0.0.1`,
      `https://[::1]`, RFC1918, `169.254.169.254`, DNS-to-private via monkeypatched
      resolver), redirect refusal, oversized stream abort, magic-byte inference,
      markdown fallback, non-skill content.
- [ ] Implement (httpx.AsyncClient injected/mockable); document residual
      DNS-rebinding risk (resolve-then-connect without IP pinning) in the module
      docstring with the mitigations list.
