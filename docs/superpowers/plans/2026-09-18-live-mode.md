# Mode Live — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** une conversation parlée en duplex avec LIA, sur la clé du fournisseur de la personne (connecteur de catégorie `live`, Gemini 3.8 Live d'abord), où la voix délègue chaque demande au moteur du chat, où le fil rapporte tout en direct, et où ce que LIA dépense est compté et affiché en fin de session.

**Architecture:** le navigateur ouvre lui-même le WebSocket chez le fournisseur avec un jeton éphémère que LIA frappe ; le modèle live n'a qu'une fonction, `send_to_lia`, que le bandeau du chat exécute en envoyant la demande par la porte du chat (`POST /chat/stream`) ; un tour délégué est un tour ordinaire (mode, outils, HITL, registres, facture) ; les échanges purement vocaux sont archivés en direct et injectés au tour suivant ; une carte de fin agrège la facture de LIA.

**Tech Stack:** FastAPI + Pydantic v2 + SQLAlchemy 2 + Redis (dorsal), `google-genai` 2.10.0 (déjà verrouillé) pour la frappe des jetons, Next.js 16 + React 19 + zustand 5 + Web Audio API (navigateur), WebSocket brut JSON vers `generativelanguage.googleapis.com`, vitest + Playwright 1.60 (`routeWebSocket`).

**Spec:** `docs/superpowers/specs/2026-09-18-live-llm-connector-design.md` (v2, A1-A14, §0 pour les trois décisions du propriétaire).

```python
"""Measure what the Live API does — before any product code relies on it.

    task live:probe -- --model gemini-3.8-live [--extended]

Seven questions the design cannot answer from documentation alone (spec §9):

1. Are ``system_instruction`` and ``tools`` accepted inside
   ``live_connect_constraints`` — and does a session opened with a DIFFERENT
   instruction get refused?
2. Does a ``NON_BLOCKING`` function call keep the model talking, and how does
   ``scheduling`` (``INTERRUPT`` vs ``WHEN_IDLE``) behave when the result
   arrives 8 s later?
3. Can a session opened with a ``uses: 1`` token be RESUMED with the same
   token and the last ``new_handle``?
4. Does a setup + immediate close (no audio) report zero tokens?
5. In which order do ``input_transcription`` / ``output_transcription`` /
   ``turn_complete`` arrive?
6. Which fields of ``models.list()`` say a model is live-capable?
7. Can a late text be pushed as client content after a tool call was cancelled?

Nothing here touches the database. The only network call is to the provider,
on the operator's TEST key, and every figure printed is anonymous.
"""

from __future__ import annotations

import argparse
import asyncio
import base64
import json
import math
import os
import struct
import sys
import time
from datetime import UTC, datetime, timedelta
from typing import Any

from google import genai
from google.genai import types

INSTRUCTION = "You are a voice assistant. Answer in one short sentence."
OTHER_INSTRUCTION = "You are a pirate. Always say ARR."
TOOL = types.FunctionDeclaration(
    name="send_to_lia",
    description="Hand the request to the backend. Say you are checking, then wait.",
    parameters={
        "type": "object",
        "properties": {"request": {"type": "string", "description": "The request."}},
        "required": ["request"],
    },
    behavior=types.Behavior.NON_BLOCKING,
)


def _tone(seconds: float, hz: float = 440.0, rate: int = 16000) -> bytes:
    """A sine tone as 16-bit PCM — a stand-in for speech, enough to open a turn."""
    frames = int(seconds * rate)
    return b"".join(
        struct.pack("<h", int(12000 * math.sin(2 * math.pi * hz * i / rate))) for i in range(frames)
    )


def _config(instruction: str, extended: bool) -> types.LiveConnectConfig:
    return types.LiveConnectConfig(
        response_modalities=["AUDIO"],
        system_instruction=instruction,
        tools=[types.Tool(function_declarations=[TOOL])],
        session_resumption=types.SessionResumptionConfig(),
        input_audio_transcription=types.AudioTranscriptionConfig(),
        output_audio_transcription=types.AudioTranscriptionConfig(),
        context_window_compression=types.ContextWindowCompressionConfig(
            trigger_tokens=25000, sliding_window=types.SlidingWindow(target_tokens=8000)
        ),
        thinking_config=(
            types.ThinkingConfig(thinking_level="low") if extended else None
        ),
    )


async def mint(client: genai.Client, model: str, extended: bool) -> types.AuthToken:
    """Question 1: a token constrained to the model AND the instruction AND the tool."""
    now = datetime.now(UTC)
    return await client.aio.auth_tokens.create(
        config=types.CreateAuthTokenConfig(
            uses=1,
            expire_time=now + timedelta(minutes=30),
            new_session_expire_time=now + timedelta(minutes=1),
            live_connect_constraints=types.LiveConnectConstraints(
                model=model, config=_config(INSTRUCTION, extended)
            ),
            lock_additional_fields=[],
            http_options=types.HttpOptions(api_version="v1alpha"),
        )
    )


async def session_events(
    token: str, model: str, config: types.LiveConnectConfig, *, scheduling: str, handle: str | None
) -> dict[str, Any]:
    """Open a session with the ephemeral token; play a tone; answer the tool late."""
    client = genai.Client(api_key=token, http_options=types.HttpOptions(api_version="v1beta"))
    if handle:
        config = config.model_copy(
            update={"session_resumption": types.SessionResumptionConfig(handle=handle)}
        )
    report: dict[str, Any] = {"events": [], "handles": [], "usage": [], "tool_calls": []}
    started = time.monotonic()
    async with client.aio.live.connect(model=model, config=config) as session:
        await session.send_realtime_input(
            audio=types.Blob(data=_tone(1.5), mime_type="audio/pcm;rate=16000")
        )
        await session.send_realtime_input(
            text="Ask the backend what is on my calendar tomorrow, then keep talking."
        )
        deadline = time.monotonic() + 40
        async for message in session.receive():
            stamp = round(time.monotonic() - started, 2)
            if message.session_resumption_update and message.session_resumption_update.new_handle:
                report["handles"].append(message.session_resumption_update.new_handle)
            if message.usage_metadata:
                report["usage"].append(message.usage_metadata.total_token_count)
            if message.tool_call:
                for call in message.tool_call.function_calls or []:
                    report["tool_calls"].append({"t": stamp, "name": call.name, "args": call.args})
                    await asyncio.sleep(8)  # the backend "works"
                    await session.send_tool_response(
                        function_responses=[
                            types.FunctionResponse(
                                id=call.id,
                                name=call.name,
                                response={"result": "Tomorrow: two meetings, 9 and 14."},
                                scheduling=scheduling,
                            )
                        ]
                    )
            content = message.server_content
            if content:
                if content.input_transcription:
                    report["events"].append({"t": stamp, "input": content.input_transcription.text})
                if content.output_transcription:
                    report["events"].append({"t": stamp, "output": content.output_transcription.text})
                if content.interrupted:
                    report["events"].append({"t": stamp, "interrupted": True})
                if content.turn_complete:
                    report["events"].append({"t": stamp, "turn_complete": True})
            if message.go_away:
                report["events"].append({"t": stamp, "go_away": str(message.go_away.time_left)})
            if time.monotonic() > deadline:
                break
    return report


async def probe_activation(client: genai.Client, model: str, voice: str) -> dict[str, Any]:
    """Question 4: setup + close with no audio — what does it cost?"""
    config = types.LiveConnectConfig(
        response_modalities=["AUDIO"],
        speech_config=types.SpeechConfig(
            voice_config=types.VoiceConfig(
                prebuilt_voice_config=types.PrebuiltVoiceConfig(voice_name=voice)
            )
        ),
    )
    try:
        async with client.aio.live.connect(model=model, config=config):
            return {"ok": True}
    except Exception as exc:  # noqa: BLE001 — the refusal IS the measurement
        return {"ok": False, "error": f"{type(exc).__name__}: {exc}"[:300]}


async def main() -> int:
    parser = argparse.ArgumentParser()
    parser.add_argument("--model", default="gemini-3.8-live")
    parser.add_argument("--extended", action="store_true")
    parser.add_argument("--voice", default="Kore")
    args = parser.parse_args()
    api_key = os.environ.get("LIVE_PROBE_API_KEY")
    if not api_key:
        print("LIVE_PROBE_API_KEY is not set", file=sys.stderr)
        return 2
    client = genai.Client(api_key=api_key)
    report: dict[str, Any] = {"model": args.model, "measured_at": datetime.now(UTC).isoformat()}

    models = [
        {"name": m.name, "actions": m.supported_actions}
        async for m in await client.aio.models.list()
    ]
    report["live_models"] = [
        m["name"] for m in models if "bidiGenerateContent" in (m["actions"] or [])
    ]
    report["activation_probe"] = await probe_activation(client, args.model, args.voice)
    report["activation_probe_bad_voice"] = await probe_activation(
        client, args.model, "not-a-voice"
    )

    token = await mint(client, args.model, args.extended)
    report["token_name_prefix"] = token.name[:12]
    report["interrupt"] = await session_events(
        token.name, args.model, _config(INSTRUCTION, args.extended), scheduling="INTERRUPT", handle=None
    )
    handles = report["interrupt"]["handles"]
    report["resumed_with_same_token"] = (
        await session_events(
            token.name,
            args.model,
            _config(INSTRUCTION, args.extended),
            scheduling="WHEN_IDLE",
            handle=handles[-1] if handles else None,
        )
        if handles
        else "no handle received"
    )
    try:
        await session_events(
            token.name, args.model, _config(OTHER_INSTRUCTION, args.extended), scheduling="INTERRUPT", handle=None
        )
        report["other_instruction_accepted"] = True
    except Exception as exc:  # noqa: BLE001 — a refusal is the hoped-for answer
        report["other_instruction_accepted"] = f"refused: {type(exc).__name__}: {exc}"[:200]
    print(json.dumps(report, indent=2, ensure_ascii=False))
    return 0


if __name__ == "__main__":
    raise SystemExit(asyncio.run(main()))
```

```python
"""Gemini as a live provider: what the key discovers, what LIA sends, what it mints.

The SDK client is built per call, on the PERSON's key, and never kept: a
module-level client would hold one account's credential in process memory
across requests (the singleton rule of the systemic rules).
"""

from __future__ import annotations

from collections.abc import AsyncIterator
from typing import Any

from src.core.constants import LIVE_BIDI_METHOD


async def _models_of(api_key: str) -> AsyncIterator[Any]:
    """The provider's model listing, on the given key (a seam the tests replace)."""
    from google import genai

    client = genai.Client(api_key=api_key)
    return await client.aio.models.list()


async def list_live_model_names(api_key: str) -> list[str]:
    """The models this key may open a live session on, without the ``models/`` prefix.

    Args:
        api_key: The person's provider key.

    Returns:
        Names whose ``supported_actions`` carry the live generation method.
    """
    names: list[str] = []
    async for model in await _models_of(api_key):
        actions = getattr(model, "supported_actions", None) or []
        if LIVE_BIDI_METHOD in actions:
            names.append(str(model.name).removeprefix("models/"))
    return sorted(names)
```

```python
"""What the person set about how a live conversation behaves (spec A10 bis).

Account-level, not connector-level: a change of provider must not hand the
person back reflexes they already tuned. STRICT on the way in (the request
schema refuses a word off the ladder), TOLERANT on the way out (a stored value
nobody understands is the default, never a 500 on the settings page) — the
``settings_shortcuts`` doctrine of ADR-277.
"""

from __future__ import annotations

from typing import Any, Literal

from pydantic import BaseModel, ConfigDict, Field

TalkMode = Literal["auto", "push_to_talk"]
EndOfSpeech = Literal["calm", "normal", "lively"]
ResultDelivery = Literal["interrupt", "when_idle"]


class LivePreferences(BaseModel):
    """The four reflexes, each a closed vocabulary."""

    model_config = ConfigDict(frozen=True, extra="ignore")

    interruptions: bool = Field(
        default=True, description="Whether the person's speech stops LIA mid-sentence."
    )
    talk_mode: TalkMode = Field(
        default="auto", description="Automatic voice activity detection, or push to talk."
    )
    end_of_speech: EndOfSpeech = Field(
        default="normal", description="How quickly LIA takes a pause for the end of a sentence."
    )
    result_delivery: ResultDelivery = Field(
        default="interrupt",
        description="Whether a delegated answer is announced at once or at the next pause.",
    )


def read_live_preferences(value: object) -> LivePreferences:
    """Read the stored column as it is, field by field.

    Args:
        value: Whatever the JSONB column holds.

    Returns:
        The preferences, every unreadable field at its default.
    """
    if not isinstance(value, dict):
        return LivePreferences()
    kept: dict[str, Any] = {}
    for name in LivePreferences.model_fields:
        candidate = {name: value.get(name)}
        try:
            LivePreferences.model_validate(candidate)
        except ValueError:
            continue
        if value.get(name) is not None:
            kept[name] = value[name]
    return LivePreferences.model_validate(kept)


__all__ = ["EndOfSpeech", "LivePreferences", "ResultDelivery", "TalkMode", "read_live_preferences"]
```

```python
def _client_of(api_key: str, *, api_version: str | None = None) -> Any:
    """A per-call SDK client (a seam the tests replace)."""
    from google import genai
    from google.genai import types

    if api_version:
        return genai.Client(api_key=api_key, http_options=types.HttpOptions(api_version=api_version))
    return genai.Client(api_key=api_key)


async def _models_of(api_key: str) -> AsyncIterator[Any]:
    """The provider's model listing, on the given key (a seam the tests replace)."""
    return await _client_of(api_key).aio.models.list()


async def list_live_model_names(api_key: str) -> list[str]:
    """The models this key may open a live session on, without the ``models/`` prefix."""
    names: list[str] = []
    async for model in await _models_of(api_key):
        actions = getattr(model, "supported_actions", None) or []
        if LIVE_BIDI_METHOD in actions:
            names.append(str(model.name).removeprefix("models/"))
    return sorted(names)


class GeminiLiveProvider:
    """Gemini Live API through ephemeral tokens (client → provider)."""

    provider_id = "gemini"
    connector_type = ConnectorType.GEMINI_LIVE

    async def list_models(self, api_key: str) -> list[LiveModel]:
        """Live-capable models, each with the thinking ladder its profile declares."""
        return [
            LiveModel(
                name=name,
                thinking_levels=list(resolve_reasoning_profile(_REASONING_PROVIDER, name).levels),
            )
            for name in await list_live_model_names(api_key)
        ]

    async def list_voices(self, _api_key: str) -> LiveVoicesResponse:
        """The published list, with its provenance said out loud."""
        return LiveVoicesResponse(
            voices=[LiveVoice(name=n, characteristic=c) for n, c in GEMINI_VOICES],
            provenance="published",
            published_at=GEMINI_VOICES_PUBLISHED_AT,
            source=GEMINI_VOICES_SOURCE,
        )

    def build_setup(self, inputs: LiveSetupInputs) -> dict[str, Any]:
        """The ``setup`` message the browser sends first, as documented JSON."""
        generation: dict[str, Any] = {
            "responseModalities": ["AUDIO"],
            "speechConfig": {"voiceConfig": {"prebuiltVoiceConfig": {"voiceName": inputs.voice}}},
        }
        if inputs.thinking_level:
            generation["thinkingConfig"] = {"thinkingLevel": inputs.thinking_level}
        return {
            "model": f"models/{inputs.model}",
            "generationConfig": generation,
            "systemInstruction": {"parts": [{"text": inputs.system_instruction}]},
            "tools": [{"functionDeclarations": [inputs.tool_declaration]}],
            "realtimeInputConfig": _realtime_input(inputs.preferences),
            "inputAudioTranscription": {},
            "outputAudioTranscription": {},
            "sessionResumption": {},
            "contextWindowCompression": {
                "triggerTokens": inputs.trigger_tokens,
                "slidingWindow": {"targetTokens": inputs.target_tokens},
            },
        }

    async def mint(
        self,
        api_key: str,
        inputs: LiveSetupInputs,
        *,
        expires_at: datetime,
        connect_deadline_at: datetime,
    ) -> LiveCredential:
        """An ephemeral token locked to the model and the setup (spec A4)."""
        from google.genai import types

        config = types.CreateAuthTokenConfig(
            uses=1,
            expire_time=expires_at,
            new_session_expire_time=connect_deadline_at,
            live_connect_constraints=types.LiveConnectConstraints(
                model=inputs.model, config=_sdk_config(inputs)
            ),
            lock_additional_fields=[],
            http_options=types.HttpOptions(api_version="v1alpha"),
        )
        token = await _client_of(api_key).aio.auth_tokens.create(config=config)
        return LiveCredential(
            name=str(token.name), expires_at=expires_at, connect_deadline_at=connect_deadline_at
        )

    async def probe(
        self, api_key: str, model: str, voice: str, *, timeout: float
    ) -> tuple[bool, str]:
        """Open a session on the pair and close it: the provider is the authority."""
        from google.genai import types

        config = types.LiveConnectConfig(
            response_modalities=["AUDIO"],
            speech_config=types.SpeechConfig(
                voice_config=types.VoiceConfig(
                    prebuilt_voice_config=types.PrebuiltVoiceConfig(voice_name=voice)
                )
            ),
        )
        client = _client_of(api_key)

        async def _open_and_close() -> None:
            async with client.aio.live.connect(model=model, config=config):
                return None

        try:
            await asyncio.wait_for(_open_and_close(), timeout=timeout)
        except TimeoutError:
            return False, "the provider did not answer in time"
        except Exception as exc:  # noqa: BLE001 - the refusal is the answer we report
            return False, f"{type(exc).__name__}: {exc}"
        return True, "ok"


def _realtime_input(prefs: LivePreferences) -> dict[str, Any]:
    sensitivity, silence_ms = _END_OF_SPEECH[prefs.end_of_speech]
    detection: dict[str, Any] = {"disabled": prefs.talk_mode == "push_to_talk", "silenceDurationMs": silence_ms}
    if sensitivity:
        detection["endOfSpeechSensitivity"] = sensitivity
    return {
        "automaticActivityDetection": detection,
        "activityHandling": "START_OF_ACTIVITY_INTERRUPTS" if prefs.interruptions else "NO_INTERRUPTION",
    }


def _sdk_config(inputs: LiveSetupInputs) -> Any:
    """The same setup, in the SDK's typed shape, for the token constraint."""
    from google.genai import types

    declaration = types.FunctionDeclaration(
        name=inputs.tool_declaration["name"],
        description=inputs.tool_declaration["description"],
        parameters=inputs.tool_declaration["parameters"],
        behavior=types.Behavior.NON_BLOCKING,
    )
    return types.LiveConnectConfig(
        response_modalities=["AUDIO"],
        system_instruction=inputs.system_instruction,
        tools=[types.Tool(function_declarations=[declaration])],
        session_resumption=types.SessionResumptionConfig(),
    )
```

```python
"""Where a live session lives between two requests: Redis, never process memory.

Four uvicorn workers serve the same account (ADR-271): the mint, the turns and
the end may each land on a different one, so the record is in Redis. The claim
follows the ``shared_flight`` doctrine — a token the OWNER compares before
deleting; ``SET NX`` then an unconditional ``DELETE`` is the forbidden shape.
The instance cap is a sorted set scored by expiry, pruned on read: a soft
bound, sized for the delegated-turn load, never a security boundary.
"""

from __future__ import annotations

import json
import uuid
from dataclasses import asdict, dataclass
from datetime import UTC, datetime
from typing import Any, Final

from redis.asyncio import Redis

from src.core.constants import REDIS_KEY_LIVE_ACTIVE, REDIS_KEY_LIVE_SESSION_PREFIX

#: Delete the record only if its token is the caller's (compare-and-delete).
_RELEASE: Final = """
local v = redis.call('get', KEYS[1])
if not v then return 0 end
if cjson.decode(v)['token'] == ARGV[1] then return redis.call('del', KEYS[1]) end
return 0
"""


@dataclass(frozen=True, slots=True)
class LiveSessionRecord:
    """The one session an account holds."""

    session_id: str
    user_id: uuid.UUID
    provider: str
    model: str
    run_id: str
    started_at: datetime
    token: str

    def to_json(self) -> str:
        payload: dict[str, Any] = asdict(self)
        payload["user_id"] = str(self.user_id)
        payload["started_at"] = self.started_at.isoformat()
        return json.dumps(payload)

    @classmethod
    def from_json(cls, raw: str) -> LiveSessionRecord:
        payload = json.loads(raw)
        return cls(
            session_id=payload["session_id"],
            user_id=uuid.UUID(payload["user_id"]),
            provider=payload["provider"],
            model=payload["model"],
            run_id=payload["run_id"],
            started_at=datetime.fromisoformat(payload["started_at"]),
            token=payload["token"],
        )


class LiveSessionStore:
    """Claim, read, release — and the instance-wide count."""

    def __init__(self, redis: Redis) -> None:
        self._redis = redis

    @staticmethod
    def _key(user_id: uuid.UUID) -> str:
        return f"{REDIS_KEY_LIVE_SESSION_PREFIX}{user_id}"

    async def claim(self, record: LiveSessionRecord, *, ttl_seconds: int) -> bool:
        """Hold the account's one session slot; False when it is already held."""
        return bool(await self._redis.set(self._key(record.user_id), record.to_json(), nx=True, ex=ttl_seconds))

    async def get(self, user_id: uuid.UUID) -> LiveSessionRecord | None:
        raw = await self._redis.get(self._key(user_id))
        if raw is None:
            return None
        return LiveSessionRecord.from_json(raw.decode() if isinstance(raw, bytes) else raw)

    async def release(self, user_id: uuid.UUID, token: str) -> bool:
        """Free the slot if — and only if — the caller holds it."""
        return bool(await self._redis.eval(_RELEASE, 1, self._key(user_id), token))

    async def register_active(self, session_id: str, expires_at: datetime) -> None:
        await self._redis.zadd(REDIS_KEY_LIVE_ACTIVE, {session_id: expires_at.timestamp()})

    async def unregister_active(self, session_id: str) -> None:
        await self._redis.zrem(REDIS_KEY_LIVE_ACTIVE, session_id)

    async def count_active(self, now: datetime | None = None) -> int:
        """Sessions whose expiry is still ahead — the pruned count."""
        stamp = (now or datetime.now(UTC)).timestamp()
        await self._redis.zremrangebyscore(REDIS_KEY_LIVE_ACTIVE, "-inf", stamp)
        return int(await self._redis.zcard(REDIS_KEY_LIVE_ACTIVE))


__all__ = ["LiveSessionRecord", "LiveSessionStore"]
```

```python
The user row of every delegated turn is stamped with the session id (Task 13);
its ``run_id`` names the per-run summary the chat meter already reads. This
module reads the message table by that stamp — a key a hidden run never writes
— and is declared ``WHOLE_RECORD`` in ``conversations/message_readers`` for it.
"""

from __future__ import annotations

from uuid import UUID

from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from src.core.field_names import FIELD_LIVE_SESSION_ID, FIELD_RUN_ID
from src.domains.chat.repository import ChatRepository
from src.domains.conversations.models import ConversationMessage
from src.domains.live.schemas import LiveUsage


async def session_run_ids(
    db: AsyncSession, *, conversation_id: UUID, live_session_id: str
) -> list[str]:
    """The run ids of every delegated turn of a session, oldest first.

    Args:
        db: Session.
        conversation_id: The person's conversation.
        live_session_id: The session.

    Returns:
        Distinct run ids, in first-seen order.
    """
    stmt = (
        select(ConversationMessage.message_metadata[FIELD_RUN_ID].astext)
        .where(
            ConversationMessage.conversation_id == conversation_id,
            ConversationMessage.role == "user",
            ConversationMessage.message_metadata[FIELD_LIVE_SESSION_ID].astext == live_session_id,
        )
        .order_by(ConversationMessage.created_at.asc())
    )
    seen: dict[str, None] = {}
    for run_id in (await db.execute(stmt)).scalars():
        if run_id:
            seen.setdefault(str(run_id), None)
    return list(seen)


async def aggregate_usage(db: AsyncSession, run_ids: list[str]) -> LiveUsage | None:
    """LIA's spend over the given runs, or None when nothing was recorded.

    Args:
        db: Session.
        run_ids: The delegated turns' run ids.

    Returns:
        The sums in the chat meter's vocabulary.
    """
    if not run_ids:
        return None
    summaries = await ChatRepository(db).get_token_summaries_by_run_ids(run_ids)
    if not summaries:
        return None
    rows = list(summaries.values())
    return LiveUsage(
        tokens_in=sum(int(r.total_prompt_tokens or 0) for r in rows),
        tokens_out=sum(int(r.total_completion_tokens or 0) for r in rows),
        tokens_cache=sum(int(r.total_cached_tokens or 0) for r in rows),
        cost_eur=float(sum(r.total_cost_eur or 0 for r in rows)),
        google_api_requests=sum(int(r.total_google_api_requests or 0) for r in rows),
    )


__all__ = ["aggregate_usage", "session_run_ids"]
```

```ts
/** Base64 ↔ ArrayBuffer, chunked so a 40 ms frame never blows the call stack. */

export function arrayBufferToBase64(buffer: ArrayBuffer): string {
  const bytes = new Uint8Array(buffer);
  let binary = '';
  const step = 0x8000;
  for (let i = 0; i < bytes.length; i += step) {
    binary += String.fromCharCode(...bytes.subarray(i, i + step));
  }
  return btoa(binary);
}

export function base64ToArrayBuffer(base64: string): ArrayBuffer {
  const binary = atob(base64);
  const bytes = new Uint8Array(binary.length);
  for (let i = 0; i < binary.length; i++) bytes[i] = binary.charCodeAt(i);
  return bytes.buffer;
}
```

```ts
/**
 * Gemini Live API over a raw WebSocket (spec A2, A12).
 *
 * The protocol is the documented one and nothing more: one `setup` frame
 * first, then `realtimeInput` / `clientContent` / `toolResponse` out, and the
 * server's `serverContent` / `toolCall` / `toolCallCancellation` / `goAway` /
 * `sessionResumptionUpdate` in. No SDK: the messages are short JSON, and a
 * second provider will not share them anyway.
 */
import { arrayBufferToBase64, base64ToArrayBuffer } from '../base64';
import type { LiveTransport } from '../transport';
import type {
  LiveConnectOptions,
  LiveResultScheduling,
  LiveToolCall,
  LiveTransportEvents,
} from '../types';

export const GEMINI_LIVE_WS_URL =
  'wss://generativelanguage.googleapis.com/ws/google.ai.generativelanguage.v1beta.GenerativeService.BidiGenerateContent';

const INPUT_MIME = 'audio/pcm;rate=16000';

/** `"12s"` / `"1.5s"` → milliseconds; anything unreadable → 0. */
function durationToMs(raw: unknown): number {
  if (typeof raw !== 'string') return 0;
  const seconds = Number.parseFloat(raw.replace(/s$/, ''));
  return Number.isFinite(seconds) ? Math.max(0, Math.round(seconds * 1000)) : 0;
}

type Json = Record<string, unknown>;

function asRecord(value: unknown): Json | null {
  return value !== null && typeof value === 'object' ? (value as Json) : null;
}

export class GeminiLiveTransport implements LiveTransport {
  private socket: WebSocket | null = null;
  private events: LiveTransportEvents = {};

  get isOpen(): boolean {
    return this.socket?.readyState === WebSocket.OPEN;
  }

  connect(options: LiveConnectOptions, events: LiveTransportEvents): Promise<void> {
    this.events = events;
    const setup: Json = { ...options.setup };
    if (options.resumptionHandle) {
      setup.sessionResumption = { handle: options.resumptionHandle };
    }
    return new Promise((resolve, reject) => {
      let settled = false;
      const socket = new WebSocket(
        `${GEMINI_LIVE_WS_URL}?access_token=${encodeURIComponent(options.credential)}`
      );
      this.socket = socket;
      socket.onopen = () => socket.send(JSON.stringify({ setup }));
      socket.onerror = () => {
        const error = new Error('live_socket_error');
        if (!settled) {
          settled = true;
          reject(error);
        }
        this.events.onError?.(error);
      };
      socket.onclose = event => {
        if (!settled) {
          settled = true;
          reject(new Error(`live_socket_closed_${event.code}`));
        }
        this.events.onClosed?.(event.code, event.reason);
      };
      socket.onmessage = event => {
        let message: Json | null;
        try {
          message = asRecord(JSON.parse(String(event.data)));
        } catch (error) {
          this.events.onError?.(error instanceof Error ? error : new Error('live_bad_frame'));
          return;
        }
        if (!message) return;
        if ('setupComplete' in message && !settled) {
          settled = true;
          this.events.onSetupComplete?.();
          resolve();
        }
        this.dispatch(message);
      };
    });
  }

  private dispatch(message: Json): void {
    const content = asRecord(message.serverContent);
    if (content) this.dispatchContent(content);
    const toolCall = asRecord(message.toolCall);
    if (toolCall && Array.isArray(toolCall.functionCalls)) {
      const calls: LiveToolCall[] = toolCall.functionCalls
        .map(asRecord)
        .filter((c): c is Json => c !== null)
        .map(c => ({
          id: String(c.id ?? ''),
          name: String(c.name ?? ''),
          args: asRecord(c.args) ?? {},
        }));
      this.events.onToolCall?.(calls);
    }
    const cancellation = asRecord(message.toolCallCancellation);
    if (cancellation && Array.isArray(cancellation.ids)) {
      this.events.onToolCallCancellation?.(cancellation.ids.map(String));
    }
    const goAway = asRecord(message.goAway);
    if (goAway) this.events.onGoAway?.(durationToMs(goAway.timeLeft));
    const resumption = asRecord(message.sessionResumptionUpdate);
    if (resumption && typeof resumption.newHandle === 'string' && resumption.newHandle) {
      this.events.onResumption?.(resumption.newHandle, Boolean(resumption.resumable));
    }
  }

  private dispatchContent(content: Json): void {
    const modelTurn = asRecord(content.modelTurn);
    const parts = modelTurn && Array.isArray(modelTurn.parts) ? modelTurn.parts : [];
    for (const raw of parts) {
      const part = asRecord(raw);
      const inline = part ? asRecord(part.inlineData) : null;
      if (inline && typeof inline.data === 'string') {
        this.events.onAudio?.(base64ToArrayBuffer(inline.data));
      }
    }
    const input = asRecord(content.inputTranscription);
    if (input && typeof input.text === 'string' && input.text) {
      this.events.onTranscript?.('user', input.text);
    }
    const output = asRecord(content.outputTranscription);
    if (output && typeof output.text === 'string' && output.text) {
      this.events.onTranscript?.('assistant', output.text);
    }
    if (content.interrupted === true) this.events.onInterrupted?.();
    if (content.turnComplete === true) this.events.onTurnComplete?.();
  }

  private send(payload: Json): void {
    if (!this.isOpen || !this.socket) return;
    this.socket.send(JSON.stringify(payload));
  }

  sendAudio(pcm16: ArrayBuffer): void {
    this.send({ realtimeInput: { audio: { mimeType: INPUT_MIME, data: arrayBufferToBase64(pcm16) } } });
  }

  sendText(text: string): void {
    this.send({ clientContent: { turns: [{ role: 'user', parts: [{ text }] }], turnComplete: true } });
  }

  sendToolResponse(id: string, name: string, result: string, scheduling: LiveResultScheduling): void {
    this.send({ toolResponse: { functionResponses: [{ id, name, response: { result }, scheduling }] } });
  }

  close(): void {
    const socket = this.socket;
    this.socket = null;
    if (socket && socket.readyState !== WebSocket.CLOSED) socket.close(1000, '');
  }
}
```

```ts
/**
 * A gapless player for the provider's raw PCM stream (spec §1.5, point 1).
 *
 * `AudioQueue` decodes ENCODED chunks through `decodeAudioData`; a live stream
 * is raw 16-bit PCM at 24 kHz arriving every few tens of milliseconds, and an
 * interruption must empty the queue at once. So: one `AudioContext` at the
 * provider's rate, one `AudioBufferSourceNode` per chunk scheduled on the
 * context clock, and `flush()` that stops them all. The iOS rules AudioQueue
 * learned still apply: the context is resumed on a user gesture (`warmup`).
 */
import { LIVE_OUTPUT_SAMPLE_RATE } from '@/lib/constants';

type SpeakingListener = (speaking: boolean) => void;

export class PcmStreamPlayer {
  private context: AudioContext | null = null;
  private nextStartTime = 0;
  private sources = new Set<AudioBufferSourceNode>();
  private speaking = false;
  private listener: SpeakingListener | null = null;
  private endTimer: ReturnType<typeof setTimeout> | null = null;

  get isSpeaking(): boolean {
    return this.speaking;
  }

  onSpeakingChange(listener: SpeakingListener): void {
    this.listener = listener;
  }

  /** Create or resume the context — call from a user gesture (iOS). */
  async warmup(): Promise<void> {
    if (!this.context) {
      this.context = new AudioContext({ sampleRate: LIVE_OUTPUT_SAMPLE_RATE });
    }
    if (this.context.state === 'suspended') await this.context.resume();
  }

  enqueue(pcm16: ArrayBuffer): void {
    const context = this.context;
    if (!context) return;
    const samples = new Int16Array(pcm16);
    const buffer = context.createBuffer(1, samples.length, LIVE_OUTPUT_SAMPLE_RATE);
    const channel = buffer.getChannelData(0);
    for (let i = 0; i < samples.length; i++) channel[i] = samples[i] / 0x8000;
    const source = context.createBufferSource();
    source.buffer = buffer;
    source.connect(context.destination);
    const startAt = Math.max(this.nextStartTime, context.currentTime);
    source.start(startAt);
    this.nextStartTime = startAt + buffer.duration;
    this.sources.add(source);
    source.onended = () => this.sources.delete(source);
    this.setSpeaking(true);
    this.armEndTimer((this.nextStartTime - context.currentTime) * 1000);
  }

  /** The provider interrupted: drop everything scheduled, now. */
  flush(): void {
    for (const source of this.sources) {
      try {
        source.stop();
      } catch {
        // already stopped
      }
    }
    this.sources.clear();
    this.nextStartTime = 0;
    this.clearEndTimer();
    this.setSpeaking(false);
  }

  dispose(): void {
    this.flush();
    void this.context?.close();
    this.context = null;
    this.listener = null;
  }

  private armEndTimer(inMs: number): void {
    this.clearEndTimer();
    this.endTimer = setTimeout(() => {
      if (this.context && this.context.currentTime >= this.nextStartTime - 0.01) {
        this.setSpeaking(false);
      }
    }, Math.max(0, inMs) + 20);
  }

  private clearEndTimer(): void {
    if (this.endTimer) clearTimeout(this.endTimer);
    this.endTimer = null;
  }

  private setSpeaking(value: boolean): void {
    if (this.speaking === value) return;
    this.speaking = value;
    this.listener?.(value);
  }
```

```ts
/**
 * The microphone as 16 kHz int16 chunks (spec §1.5, point 2).
 *
 * The SAME worklet the push-to-talk and the meeting recorder use, at a chunk
 * size the live provider wants (tens of milliseconds, not a quarter second).
 * One capture owns its stream, context and node, and releases all three.
 */
import { PCM_WORKLET_PROCESSOR_NAME, getPcmWorkletUrl } from '@/lib/audio/pcm-worklet';
import { VOICE_INPUT_SAMPLE_RATE } from '@/lib/constants';

export interface MicCaptureOptions {
  chunkSamples: number;
  onChunk: (pcm16: ArrayBuffer) => void;
}

export interface MicCapture {
  mute(on: boolean): void;
  stop(): Promise<void>;
}

export async function startMicCapture(options: MicCaptureOptions): Promise<MicCapture> {
  const stream = await navigator.mediaDevices.getUserMedia({
    audio: { channelCount: 1, sampleRate: VOICE_INPUT_SAMPLE_RATE, echoCancellation: true, noiseSuppression: true },
  });
  const context = new AudioContext({ sampleRate: VOICE_INPUT_SAMPLE_RATE });
  await context.audioWorklet.addModule(getPcmWorkletUrl(options.chunkSamples));
  const source = context.createMediaStreamSource(stream);
  const node = new AudioWorkletNode(context, PCM_WORKLET_PROCESSOR_NAME);
  let muted = false;
  node.port.onmessage = (event: MessageEvent<ArrayBuffer>) => {
    if (!muted) options.onChunk(event.data);
  };
  source.connect(node);
  return {
    mute(on: boolean) {
      muted = on;
    },
    async stop() {
      node.port.onmessage = null;
      source.disconnect();
      node.disconnect();
      for (const track of stream.getTracks()) track.stop();
      await context.close();
    },
  };
}
```

```ts
/**
 * The live session's states, as a pure function (spec A6).
 *
 * idle → minting → connecting → live ⇄ reconnecting → ending → ended
 * Every way a session ends is a NAMED outcome (`LiveOutcome`), decided by the
 * caller and carried to the API's `end`; this module only says which state
 * follows which event, and what a socket close means.
 */
import { LIVE_RECONNECT_ATTEMPTS } from '@/lib/constants';

export type LiveStatus = 'idle' | 'minting' | 'connecting' | 'live' | 'reconnecting' | 'ending' | 'ended';

export type LiveEvent =
  | { type: 'start' }
  | { type: 'minted' }
  | { type: 'setup_complete' }
  | { type: 'socket_closed' }
  | { type: 'end' }
  | { type: 'ended' }
  | { type: 'failed' };

export function transition(status: LiveStatus, event: LiveEvent): LiveStatus {
  switch (event.type) {
    case 'start':
      return status === 'idle' || status === 'ended' ? 'minting' : status;
    case 'minted':
      return status === 'minting' ? 'connecting' : status;
    case 'setup_complete':
      return status === 'connecting' || status === 'reconnecting' ? 'live' : status;
    case 'socket_closed':
      return status === 'live' || status === 'connecting' ? 'reconnecting' : status;
    case 'end':
      return status === 'ended' || status === 'idle' ? status : 'ending';
    case 'failed':
      return status === 'ended' ? status : 'ending';
    case 'ended':
      return 'ended';
  }
}

/** What to do when the socket closed while the session should go on. */
export function closeDecision(
  code: number,
  resumptionHandle: string | null,
  attempts: number
): 'reconnect' | 'provider_closed' | 'resumption_failed' {
  if (code === 1000) return 'provider_closed';
  if (!resumptionHandle) return 'provider_closed';
  return attempts >= LIVE_RECONNECT_ATTEMPTS ? 'resumption_failed' : 'reconnect';
}
```

```ts
/**
 * The bridge between the voice's one function and the chat's door (spec A3).
 *
 * `send_to_lia(request)` arrives as a tool call; the bridge sends the request
 * through the chat exactly as a typed message (the delegated turn draws itself
 * in the thread), waits for the stream to end, and hands the voice a bounded,
 * flattened answer — or LIA's pending question, which IS the result. Four
 * rules, each a test: one at a time; a bounded wait after which the turn goes
 * on in the chat; a cancelled call is never answered; the turn is never killed
 * from here (only the banner's Stop does that).
 */
import type { LiveResultScheduling, LiveToolCall } from './types';

export interface DelegationLines {
  still_working: string;
  timed_out: string;
  result_cut: string;
}

export interface DelegationDeps {
  /** Send through the chat's own door; resolves when the stream ends. */
  send: (request: string, spokenText: string | null) => Promise<void>;
  /** The last assistant answer and the pending question, read AFTER the stream ended. */
  readAnswer: () => { text: string; pendingQuestion: string | null };
  lines: DelegationLines;
  timeoutMs: number;
  resultMaxChars: number;
  scheduling: LiveResultScheduling;
  flatten: (markdown: string) => string;
}

export interface DelegationResult {
  id: string;
  name: string;
  result: string;
  scheduling: LiveResultScheduling;
}

const SPOKEN_ARG = '__spoken';

/** Markdown and cards → the prose a voice can say. */
export function flattenForVoice(markdown: string): string {
  return markdown
    .replace(/<[^>]+>/g, ' ')
    .replace(/^#{1,6}\s+(.+)$/gm, '$1.')
    .replace(/\[([^\]]+)\]\([^)]*\)/g, '$1')
    .replace(/[*_`~]+/g, '')
    .replace(/^\s*[-*+]\s+(.+)$/gm, '$1.')
    .replace(/^\s*\d+[.)]\s+(.+)$/gm, '$1.')
    .replace(/\.\./g, '.')
    .replace(/\s+/g, ' ')
    .trim();
}

export class DelegationBridge {
  private inFlight: string | null = null;
  private cancelled = new Set<string>();

  constructor(private readonly deps: DelegationDeps) {}

  get busy(): boolean {
    return this.inFlight !== null;
  }

  cancel(ids: string[]): void {
    for (const id of ids) this.cancelled.add(id);
  }

  /** Resolves to the tool response, or null when the call was cancelled meanwhile. */
  async handle(call: LiveToolCall): Promise<DelegationResult | null> {
    const request = String(call.args.request ?? '').trim();
    const spoken = typeof call.args[SPOKEN_ARG] === 'string' ? (call.args[SPOKEN_ARG] as string) : null;
    if (!request) return this.answer(call, this.deps.lines.still_working);
    if (this.inFlight) return this.answer(call, this.deps.lines.still_working);
    this.inFlight = call.id;
    const turn = this.deps.send(request, spoken).finally(() => {
      if (this.inFlight === call.id) this.inFlight = null;
    });
    const timeout = new Promise<'timeout'>(resolve =>
      setTimeout(() => resolve('timeout'), this.deps.timeoutMs)
    );
    const outcome = await Promise.race([turn.then(() => 'done' as const), timeout]);
    if (this.cancelled.has(call.id)) {
      this.cancelled.delete(call.id);
      return null;
    }
    if (outcome === 'timeout') return this.answer(call, this.deps.lines.timed_out);
    const { text, pendingQuestion } = this.deps.readAnswer();
    if (pendingQuestion) return this.answer(call, pendingQuestion);
    return this.answer(call, this.bounded(this.deps.flatten(text)));
  }

  private bounded(text: string): string {
    if (text.length <= this.deps.resultMaxChars) return text;
    return `${text.slice(0, this.deps.resultMaxChars)} ${this.deps.lines.result_cut}`;
  }

  private answer(call: LiveToolCall, result: string): DelegationResult {
    return { id: call.id, name: call.name, result, scheduling: this.deps.scheduling };
  }
}
```

```ts
'use client';

/**
 * useLiveSession — one session, from the mint to the closing card (spec A6, A7).
 *
 * Owns the transport, the microphone, the player and the delegation bridge;
 * publishes everything the banner and the eyes read into `useLiveStore`; and
 * speaks to the chat through the bindings it is handed (the chat's own
 * `sendMessage` is the door — never a request of this hook's own).
 *
 * The one-owner-of-the-microphone rule (ADR-258) is enforced by the CALLER,
 * which refuses to start while a meeting records; this hook pauses nothing.
 */
import { useCallback, useEffect, useRef } from 'react';

import apiClient from '@/lib/api-client';
import { LIVE_GO_AWAY_MARGIN_MS, LIVE_INPUT_CHUNK_SAMPLES } from '@/lib/constants';
import { DelegationBridge, flattenForVoice } from '@/lib/live/delegation';
import { startMicCapture, type MicCapture } from '@/lib/live/mic-capture';
import { PcmStreamPlayer } from '@/lib/live/pcm-player';
import { closeDecision } from '@/lib/live/session-machine';
import { createLiveTransport, type LiveTransport } from '@/lib/live/transport';
import type { LiveEndResponse, LiveOutcome, LiveSessionStart, LiveToolCall } from '@/lib/live/types';
import { logger } from '@/lib/logger';
import { useLiveStore } from '@/stores/liveStore';
import type { Message } from '@/types/chat';

export interface LiveSpokenMeta {
  live_session_id: string;
  spoken_text: string | null;
}

export interface LiveChatBindings {
  sendMessage: (content: string, meta: LiveSpokenMeta) => Promise<void>;
  stopGeneration: () => Promise<void>;
  appendMessage: (message: Message) => void;
  readAnswer: () => { text: string; pendingQuestion: string | null };
}

interface LiveConfig {
  delegation_lines: { still_working: string; timed_out: string; result_cut: string };
  idle_timeout_seconds: number;
  hidden_grace_seconds: number;
}

/** Characters per token the project's estimator assumes; CJK counts one em per glyph (ADR-274). */
const CHARS_PER_TOKEN = 4;

function generateId(): string {
  return typeof crypto !== 'undefined' && 'randomUUID' in crypto ? crypto.randomUUID() : String(Date.now());
}

export function useLiveSession(chat: LiveChatBindings) {
  const store = useLiveStore;
  const transportRef = useRef<LiveTransport | null>(null);
  const playerRef = useRef<PcmStreamPlayer | null>(null);
  const micRef = useRef<MicCapture | null>(null);
  const bridgeRef = useRef<DelegationBridge | null>(null);
  const startRef = useRef<LiveSessionStart | null>(null);
  const handleRef = useRef<string | null>(null);
  const attemptsRef = useRef(0);
  const turnRef = useRef<{ user: string; assistant: string; startedAt: number; delegated: boolean }>({ user: '', assistant: '', startedAt: 0, delegated: false });
  const countsRef = useRef({ delegations: 0, voiceTurns: 0 });
  const idleTimerRef = useRef<ReturnType<typeof setTimeout> | null>(null);
  const configRef = useRef<LiveConfig | null>(null);
  const endingRef = useRef(false);

  const armIdle = useCallback(() => {
    if (idleTimerRef.current) clearTimeout(idleTimerRef.current);
    const seconds = configRef.current?.idle_timeout_seconds ?? 300;
    idleTimerRef.current = setTimeout(() => void end('idle_timeout'), seconds * 1000);
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, []);

  const archiveTurn = useCallback(async () => {
    const start = startRef.current;
    const turn = turnRef.current;
    if (!start) return;
    const userText = turn.delegated ? null : turn.user.trim() || null;
    const assistantText = turn.assistant.trim() || null;
    turnRef.current = { user: '', assistant: '', startedAt: Date.now(), delegated: false };
    if (!userText && !assistantText) return;
    countsRef.current.voiceTurns += 1;
    const startedAt = new Date(turn.startedAt || Date.now()).toISOString();
    const endedAt = new Date().toISOString();
    try {
      await apiClient.post(`/live/sessions/${start.session_id}/turns`, {
        user_text: userText?.slice(0, start.turn_text_max_chars) ?? null,
        assistant_text: assistantText?.slice(0, start.turn_text_max_chars) ?? null,
        started_at: startedAt,
        ended_at: endedAt,
      });
      const at = new Date();
      if (userText) chat.appendMessage({ id: generateId(), role: 'user', content: userText, timestamp: at, metadata: { type: 'live_turn', live_session_id: start.session_id } });
      if (assistantText) chat.appendMessage({ id: generateId(), role: 'assistant', content: assistantText, timestamp: at, metadata: { type: 'live_turn', live_session_id: start.session_id } });
    } catch (error) {
      logger.warn('live_turn_archive_failed', { error, component: 'useLiveSession' });
    }
  }, [chat]);

  const connect = useCallback(async () => {
    const start = startRef.current;
    const transport = transportRef.current;
    if (!start || !transport) return;
    await transport.connect(
      { credential: start.credential, setup: start.setup, resumptionHandle: handleRef.current },
      {
        onSetupComplete: () => {
          attemptsRef.current = 0;
          store.getState().setStatus('live');
          armIdle();
        },
        onAudio: pcm => {
          playerRef.current?.enqueue(pcm);
          armIdle();
        },
        onTranscript: (role, text) => {
          const turn = turnRef.current;
          if (!turn.startedAt) turn.startedAt = Date.now();
          if (role === 'user') {
            turn.user += text;
            store.getState().setVoiceState('recording');
          } else {
            turn.assistant += text;
          }
          store.getState().pushCaption(role, text, false);
          armIdle();
        },
        onTurnComplete: () => {
          void archiveTurn();
          store.getState().pushCaption('assistant', '', true);
          if (!playerRef.current?.isSpeaking) store.getState().setVoiceState('idle');
        },
        onInterrupted: () => {
          playerRef.current?.flush();
          store.getState().setVoiceState('recording');
        },
        onToolCall: async calls => {
          const bridge = bridgeRef.current;
          if (!bridge) return;
          for (const call of calls) {
            turnRef.current.delegated = true;
            const spoken = turnRef.current.user.trim();
            const withSpoken: LiveToolCall = { ...call, args: { ...call.args, __spoken: spoken || null } };
            countsRef.current.delegations += 1;
            store.getState().setDelegating(true);
            store.getState().setVoiceState('processing');
            const result = await bridge.handle(withSpoken);
            store.getState().setDelegating(bridge.busy);
            if (result && transportRef.current?.isOpen) {
              transportRef.current.sendToolResponse(result.id, result.name, result.result, result.scheduling);
            }
          }
        },
        onToolCallCancellation: ids => bridgeRef.current?.cancel(ids),
        onResumption: handle => {
          handleRef.current = handle;
        },
        onGoAway: timeLeftMs => {
          store.getState().setTimeLeft(timeLeftMs);
          setTimeout(() => void reconnect(), Math.max(0, timeLeftMs - LIVE_GO_AWAY_MARGIN_MS));
        },
        onClosed: code => {
          if (endingRef.current || store.getState().status === 'ended') return;
          const decision = closeDecision(code, handleRef.current, attemptsRef.current);
          if (decision === 'reconnect') void reconnect();
          else void end(decision);
        },
        onError: error => logger.warn('live_transport_error', { error, component: 'useLiveSession' }),
      }
    );
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [archiveTurn, armIdle]);

  const reconnect = useCallback(async () => {
    if (endingRef.current) return;
    attemptsRef.current += 1;
    store.getState().setStatus('reconnecting');
    transportRef.current?.close();
    try {
      await connect();
    } catch (error) {
      logger.warn('live_reconnect_failed', { error, component: 'useLiveSession' });
      const decision = closeDecision(1006, handleRef.current, attemptsRef.current);
      if (decision === 'reconnect') void reconnect();
      else void end(decision);
    }
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [connect]);

  const end = useCallback(
    async (outcome: LiveOutcome = 'ended') => {
      if (endingRef.current) return;
      endingRef.current = true;
      const start = startRef.current;
      store.getState().setStatus('ending');
      if (idleTimerRef.current) clearTimeout(idleTimerRef.current);
      transportRef.current?.close();
      await micRef.current?.stop();
      playerRef.current?.dispose();
      await archiveTurn();
      if (start) {
        try {
          const summary = await apiClient.post<LiveEndResponse>(`/live/sessions/${start.session_id}/end`, {
            outcome,
            delegations: countsRef.current.delegations,
            voice_turns: countsRef.current.voiceTurns,
          });
          if (summary.summary_message_id) {
            chat.appendMessage({
              id: summary.summary_message_id,
              role: 'assistant',
              content: '',
              timestamp: new Date(),
              metadata: {
                type: 'live_session_summary',
                live_session_id: start.session_id,
                live_session: { outcome, duration_seconds: summary.duration_seconds, delegations: summary.delegations, voice_turns: summary.voice_turns },
                ...(summary.usage ?? {}),
              },
            });
          }
        } catch (error) {
          logger.warn('live_end_failed', { error, component: 'useLiveSession' });
        }
      }
      store.getState().finish(outcome);
      transportRef.current = null;
      micRef.current = null;
      playerRef.current = null;
      bridgeRef.current = null;
      startRef.current = null;
      handleRef.current = null;
      endingRef.current = false;
    },
    [archiveTurn, chat]
  );

  const start = useCallback(async () => {
    const state = store.getState();
    if (state.status !== 'idle' && state.status !== 'ended') return;
    endingRef.current = false;
    countsRef.current = { delegations: 0, voiceTurns: 0 };
    turnRef.current = { user: '', assistant: '', startedAt: 0, delegated: false };
    try {
      const player = new PcmStreamPlayer();
      await player.warmup(); // user gesture: the click that started the session
      player.onSpeakingChange(speaking => {
        if (speaking) store.getState().setVoiceState('speaking');
        else if (store.getState().voiceState === 'speaking') store.getState().setVoiceState('idle');
      });
      playerRef.current = player;
      configRef.current = await apiClient.get<LiveConfig>('/live/config');
      const started = await apiClient.post<LiveSessionStart>('/live/sessions', {});
      startRef.current = started;
      state.begin(started.session_id);
      store.getState().setStatus('connecting');
      bridgeRef.current = new DelegationBridge({
        send: (request, spokenText) => chat.sendMessage(request, { live_session_id: started.session_id, spoken_text: spokenText }),
        readAnswer: chat.readAnswer,
        lines: configRef.current.delegation_lines,
        timeoutMs: started.delegation_timeout_seconds * 1000,
        resultMaxChars: started.delegation_result_max_tokens * CHARS_PER_TOKEN,
        scheduling: started.preferences.result_delivery === 'when_idle' ? 'WHEN_IDLE' : 'INTERRUPT',
        flatten: flattenForVoice,
      });
      transportRef.current = createLiveTransport(started.provider);
      await connect();
      try {
        micRef.current = await startMicCapture({
          chunkSamples: LIVE_INPUT_CHUNK_SAMPLES,
          onChunk: pcm => transportRef.current?.sendAudio(pcm),
        });
      } catch {
        await end('mic_denied');
        return;
      }
      if (started.preferences.talk_mode === 'push_to_talk') {
        micRef.current.mute(true);
        store.getState().setMuted(true);
      }
    } catch (error) {
      logger.error('live_start_failed', error as Error, { component: 'useLiveSession' });
      store.getState().finish('error', error instanceof Error ? error.message : String(error));
      transportRef.current?.close();
      playerRef.current?.dispose();
    }
  }, [chat, connect, end]);

  const toggleMute = useCallback(() => {
    const muted = !store.getState().muted;
    micRef.current?.mute(muted);
    store.getState().setMuted(muted);
  }, []);

  const pushToTalk = useCallback((on: boolean) => {
    micRef.current?.mute(!on);
    store.getState().setMuted(!on);
  }, []);

  // A hidden page longer than the grace ends the session (iOS suspends audio).
  useEffect(() => {
    let timer: ReturnType<typeof setTimeout> | null = null;
    const onVisibility = () => {
      if (document.visibilityState === 'hidden') {
        const grace = (configRef.current?.hidden_grace_seconds ?? 20) * 1000;
        timer = setTimeout(() => {
          if (store.getState().status === 'live' || store.getState().status === 'reconnecting') void end('hidden');
        }, grace);
      } else if (timer) {
        clearTimeout(timer);
        timer = null;
      }
    };
    document.addEventListener('visibilitychange', onVisibility);
    return () => {
      document.removeEventListener('visibilitychange', onVisibility);
      if (timer) clearTimeout(timer);
    };
  }, [end]);

  // Unmount = end, without leaving a socket alive.
  useEffect(() => () => {
    if (store.getState().status === 'live' || store.getState().status === 'connecting') void end('ended');
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, []);

  return { start, end, toggleMute, pushToTalk };
}
```

```ts
/**
 * The live connector form (spec A10): key → validate → discover models and
 * voices → choose → activate. The provider is the authority on the pair: the
 * activation probes it, and its refusal comes back in its own words.
 */
import { useCallback, useState } from 'react';
import { useTranslation } from 'react-i18next';

import apiClient from '@/lib/api-client';
import { logger } from '@/lib/logger';

export interface LiveModelOption { name: string; thinking_levels: string[] }
export interface LiveVoiceOption { name: string; characteristic: string }
export interface LiveVoicesListing {
  voices: LiveVoiceOption[];
  provenance: 'discovered' | 'published';
  published_at: string | null;
  source: string | null;
}

interface ValidateResponse { is_valid: boolean; message: string }
interface DiscoverResponse { models: LiveModelOption[]; default_model: string }

export function useLiveConnector({ onSuccess }: { onSuccess?: () => void } = {}) {
  const { t } = useTranslation();
  const [apiKey, setApiKeyRaw] = useState('');
  const [models, setModels] = useState<LiveModelOption[]>([]);
  const [voices, setVoices] = useState<LiveVoicesListing | null>(null);
  const [model, setModel] = useState<string | null>(null);
  const [voice, setVoice] = useState<string | null>(null);
  const [thinkingLevel, setThinkingLevel] = useState<string | null>(null);
  const [isValidating, setIsValidating] = useState(false);
  const [isActivating, setIsActivating] = useState(false);
  const [activated, setActivated] = useState(false);
  const [error, setError] = useState<string | null>(null);

  const setApiKey = useCallback((value: string) => {
    setApiKeyRaw(value);
    setModels([]);
    setModel(null);
  }, []);

  const validateKey = useCallback(async () => {
    setIsValidating(true);
    setError(null);
    try {
      const check = await apiClient.post<ValidateResponse>('/connectors/api-key/validate', { api_key: apiKey, connector_type: 'gemini_live' });
      if (!check.is_valid) {
        setError(t('settings.connectors.live.invalid_key'));
        return;
      }
      const [discovered, listing] = await Promise.all([
        apiClient.post<DiscoverResponse>('/live/models/discover', { api_key: apiKey }),
        apiClient.get<LiveVoicesListing>('/live/voices/published'),
      ]);
      setModels(discovered.models);
      setModel(discovered.models.some(m => m.name === discovered.default_model) ? discovered.default_model : discovered.models[0]?.name ?? null);
      setVoices(listing);
      setVoice(listing.voices[0]?.name ?? null);
    } catch (err) {
      const msg = err instanceof Error ? err.message : 'Validation failed';
      logger.error('live_key_validation_failed', err as Error, { component: 'useLiveConnector' });
      setError(msg);
    } finally {
      setIsValidating(false);
    }
  }, [apiKey, t]);

  const selectedModel = models.find(m => m.name === model) ?? null;
  const thinkingOffered = (selectedModel?.thinking_levels ?? []).length > 0;

  const activate = useCallback(async () => {
    if (!model || !voice) return;
    setIsActivating(true);
    setError(null);
    try {
      await apiClient.post('/live/connector/activate', {
        api_key: apiKey,
        model,
        voice,
        thinking_level: thinkingOffered ? thinkingLevel ?? selectedModel?.thinking_levels[0] ?? null : null,
      });
      setActivated(true);
      onSuccess?.();
    } catch (err) {
      const msg = err instanceof Error ? err.message : 'Activation failed';
      logger.error('live_activation_failed', err as Error, { component: 'useLiveConnector' });
      setError(msg);
    } finally {
      setIsActivating(false);
    }
  }, [apiKey, model, voice, thinkingLevel, thinkingOffered, selectedModel, onSuccess]);

  return {
    apiKey, setApiKey, models, voices, model, setModel, voice, setVoice,
    thinkingLevel, setThinkingLevel, thinkingOffered, thinkingLevels: selectedModel?.thinking_levels ?? [],
    validateKey, activate, isValidating, isActivating, activated, error,
    canActivate: Boolean(model && voice && !isActivating && !isValidating),
  };
}
```

```ts
/**
 * How the live session talks to the chat (spec A3): the chat's own
 * `sendMessage`, and a read of the LAST answer once the stream ended. Refs,
 * because the messages change on every token and the bridge needs them only
 * at the instant the stream resolves.

import { useEffect, useMemo, useRef } from 'react';

import type { LiveChatBindings, LiveSpokenMeta } from '@/hooks/useLiveSession';
import { hitlAwaitsUser } from '@/lib/chat-surfaces';
import type { Message } from '@/types/chat';

interface ChatLike {
  messages: Message[];
  hitl: { status: string; payload?: { generated_question?: string | null } | null };
  sendMessage: (content: string, attachmentIds?: string[], attachmentsMeta?: undefined, sttMeta?: undefined, hitlDecision?: undefined, directive?: undefined, liveMeta?: LiveSpokenMeta) => Promise<void>;
  stopGeneration: () => Promise<void>;
  appendMessage: (message: Message) => void;
}

export function useLiveChatBindings(chat: ChatLike): LiveChatBindings {
  const messagesRef = useRef(chat.messages);
  const hitlRef = useRef(chat.hitl);
  useEffect(() => {
    messagesRef.current = chat.messages;
    hitlRef.current = chat.hitl;
  });
  return useMemo(
    () => ({
      sendMessage: (content, meta) => chat.sendMessage(content, undefined, undefined, undefined, undefined, undefined, meta),
      stopGeneration: chat.stopGeneration,
      appendMessage: chat.appendMessage,
      readAnswer: () => {
        const hitl = hitlRef.current;
        if (hitlAwaitsUser(hitl.status as never)) {
          return { text: '', pendingQuestion: hitl.payload?.generated_question ?? '' };
        }
        const last = [...messagesRef.current].reverse().find(m => m.role === 'assistant');
        return { text: last?.content ?? '', pendingQuestion: null };
      },
    }),
    [chat.sendMessage, chat.stopGeneration, chat.appendMessage]
  );
}
```

```python
"""What LIA learns from the exchanges the voice held alone (spec A7, R4).

A delegated turn ran the six post-response extractions inside the graph. A
voice-only exchange ran in no graph, so its words would reach no memory and
no interest — the session's end hands them to the same extractors, once, under
the person's own switches, the operator's capabilities, and the session's run
id (a ``TrackingContext`` published here, since these extractors spend on the
ambient tracker — the TURN road of ``spend_roads``).
"""

from __future__ import annotations

import uuid
from typing import Any

import structlog
from langchain_core.messages import AIMessage, BaseMessage, HumanMessage

from src.domains.agents.services.memory_extractor import extract_memories_background
from src.domains.chat.service import TrackingContext
from src.domains.feature_switches.registry import PlatformCapability, is_capability_enabled
from src.domains.interests.services import extract_interests_background
from src.infrastructure.async_utils import safe_fire_and_forget

logger = structlog.get_logger(__name__)


def live_turn_messages(rows: list[tuple[str, str]]) -> list[BaseMessage]:
    """The archived voice-only rows as the extractors read them."""
    messages: list[BaseMessage] = []
    for role, text in rows:
        if not text.strip():
            continue
        messages.append(HumanMessage(content=text) if role == "user" else AIMessage(content=text))
    return messages


async def _learn(
    *, user: Any, conversation_id: uuid.UUID, run_id: str, messages: list[BaseMessage], language: str
) -> None:
    async with TrackingContext(run_id, user.id, f"live_{run_id}", conversation_id):
        if getattr(user, "memory_enabled", False) and await is_capability_enabled(PlatformCapability.MEMORY):
            await extract_memories_background(
                str(user.id),
                messages,
                f"live_{run_id}",
                personality_instruction=None,
                conversation_id=str(conversation_id),
                parent_run_id=run_id,
            )
        if getattr(user, "interest_extraction_enabled", False) and await is_capability_enabled(
            PlatformCapability.INTERESTS
        ):
            await extract_interests_background(
                str(user.id),
                messages,
                f"live_{run_id}",
                conversation_id=str(conversation_id),
                user_language=language,
                parent_run_id=run_id,
            )


async def schedule_live_learning(
    *,
    user: Any,
    conversation_id: uuid.UUID,
    run_id: str,
    rows: list[tuple[str, str]],
    language: str,
    run_inline: bool = False,
) -> None:
    """Hand the voice-only exchanges to the extractors, never raising.

    Args:
        user: The account (its own switches are read here).
        conversation_id: The conversation the rows belong to.
        run_id: The session's run id — what the spend is filed under.
        rows: ``(role, text)`` of every ``live_turn`` row, in order.
        language: The person's backend-canonical language.
        run_inline: Tests only — await instead of scheduling.
    """
    messages = live_turn_messages(rows)
    if not messages:
        return
    coroutine = _learn(
        user=user, conversation_id=conversation_id, run_id=run_id, messages=messages, language=language
    )
    if run_inline:
        try:
            await coroutine
        except Exception as exc:  # noqa: BLE001 - learning must never break the end of a session
            logger.warning("live_learning_failed", run_id=run_id, error_type=type(exc).__name__)
        return
    safe_fire_and_forget(coroutine, name="live_learning", run_id=run_id)


__all__ = ["live_turn_messages", "schedule_live_learning"]
```
