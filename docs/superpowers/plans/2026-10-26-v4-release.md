**Goal:** Publish and deploy v4.0.0, covering the five commits after v3.7.0 and the staged World integration, with accurate public presentation in all six languages.

**Scope:** Existing main checkout; preserve the initial staged snapshot. No worktree reset, bypassed hook, lowered quality gate or unverified certification claim.

- [x] Inventory committed and staged behavior against current source; separate implemented World capabilities from design proposals.

- [x] Reconcile technical documentation, ADR coverage and functional/technical/decision maps with shipped behavior and installer contracts.

- [ ] Run installer tests and defaults-to-Settings contracts, documentation/i18n/static gates, frontend/backend and relevant integration/agent/browser/deployment suites. Correct errors and warnings at their causes.
- [ ] Review the final index against the initial inventory; commit through the normal hook and push through the secret scan.
- [ ] Wait for CI and Security on the pushed SHA, tag v4.0.0 and build/qualify the exact candidate through the release workflows.
- [ ] From a verified clean source, execute production deploy, demo down/up/verify in order; verify runtime version, SHA, readiness and public pages.

**Review focus:** Six-language key and semantic parity; chapter numbering and preserved anchor links; private World information excluded from shared presence; optional World admission/voice behavior stated accurately; screenshot provenance distinguished from reproducible fictional captures; real installer defaults and migration graph; no production deployment before the remote CI verdict.

**Validation:** Taskfile owns the commands; the release evidence records fresh outcomes, counts, warnings and any environment limitations. A green targeted suite does not replace the full required gate.
