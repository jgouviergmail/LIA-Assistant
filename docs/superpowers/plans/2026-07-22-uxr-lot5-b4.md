# UXR Lot 5 — B4: Personalizable Briefing Grid Implementation Plan

> Executed INLINE (program mandate). Program doc:
> `docs/superpowers/specs/2026-07-22-ux-refinements-program.md` (Lot 5 spec + edge
> register; arbitration 7a: per-feature JSONB column on users, new-dict rule).

**Goal:** per-user visibility toggles + ordering of the 9 briefing cards; a hidden card
is neither fetched nor cache-read (real API/LLM economy); server-persisted preferences;
keyboard-accessible reordering.

**Verified facts:** 9 sections (`SECTION_NAMES`, constants.py:72-82); `CardStatus`
enum ok/empty/error/not_configured (schemas.py:29-35); `build_cards` gathers 9
`_section()` wrappers (service.py:140-186); synthesis consumers exclude non-OK
automatically (`_iter_cards` llm.py:345, `_count_sections_with_data` service.py:531 —
counts 6 legacy sections only, pre-existing); `_read_cards_from_cache`
(service.py:461) needs the hidden filter too. **Pre-existing drift found:**
`RefreshSectionLiteral` (schemas.py:485-487) lists only 6 sections + 'all' —
for_you/tasks/documents cannot be refreshed; fixed + PINNED by the new completeness
test.

## Backend

- **B1** `CardStatus.HIDDEN = "hidden"` (additive); `BriefingPreferences` schema
  (`hidden: list[str]`, `order: list[str]`, names validated against `SECTION_NAMES`,
  422 otherwise) + `sanitize_briefing_preferences(raw_jsonb)` reader (unknown names
  filtered, order deduped + completed canonically) in a NEW module
  `briefing/preferences.py` (SLOC discipline) — tests first.
- **B2** `users.briefing_preferences: JSONB nullable` + Alembic migration
  (upgrade/downgrade, single head) + replay-check.
- **B3** Service: `build_cards` + `_read_cards_from_cache` read
  `sanitize_briefing_preferences(self.user.briefing_preferences)`; hidden sections get
  `_hidden_section()` placeholders (status=HIDDEN, no fetch, no cache IO) — tests
  assert the fetcher is NOT called for a hidden section and statuses propagate.
- **B4** Router: GET `/briefing/preferences` (sanitized view) + PUT
  `/briefing/preferences` (validated replace; plain new-dict assignment); refresh of a
  hidden section → 400 stable code `section_hidden`; `RefreshSectionLiteral` completed
  to all 9 + 'all'.
- **B5** Completeness guard test: prefs-validation vocabulary == SECTION_NAMES ==
  RefreshSectionLiteral∖{'all'} == CardsBundle model fields (any future section must
  register everywhere or CI refuses).

## Frontend

- **F1** types/briefing.ts: `'hidden'` status + preferences types;
  `useBriefingPreferences` hook (GET/PUT).
- **F2** TodayBriefing renders from an ordered visible list via a pinned
  SECTION→component mapping (completeness test vs the 9 names); staggerIndex from
  position; hidden/`hidden`-status never rendered; all-hidden → CTA line linking the
  settings.
- **F3** Settings section `BriefingGridSettings` (new component + `moveSection` pure
  helper): per-card visibility switch + ↑/↓ buttons (aria-labelled with the card title,
  focus kept, polite announcement) + HTML5 drag-and-drop as pointer enhancement;
  optimistic PUT with rollback on error.
- **F4** i18n ×6 (settings labels; card names reuse
  `dashboard.briefing.cards.*.title`); a11y + hooks + CC ratchets.

## Edge register (enforced in tests)
- NULL prefs → all visible, canonical order (zero-migration behavior).
- Unknown stored names filtered on read; order completed canonically for missing
  sections (future sections default-visible at canonical position).
- All 9 hidden → grid CTA; synthesis legitimately skipped (<2 threshold); greeting OK.
- Hidden `for_you` never starves the heartbeat (own repo access — program doc).
- Reminders TTL=0 special case mirrored (placeholder instead of the sleep(0) slot).
- Refresh 'all' skips hidden; direct refresh of hidden → 400 `section_hidden`.
- Re-shown section may serve its still-valid cache (normal staleness, accepted).

Gates: backend fast suite + lint + replay-check; frontend suite + tsc + lint +
coverage + 3 ratchets; runtime proof: toggle a card off → /cards response carries
`hidden` + fetcher log absent; reorder persists after F5.
