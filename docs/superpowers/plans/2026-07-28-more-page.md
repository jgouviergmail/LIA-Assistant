# "Encore +" Public Page (`/more`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task (inline execution — user directive: no subagents). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the sixth public page `/more` — 26 animated "small attention" cards in 6 moment
sections — fully integrated (header, footers, sitemap, public routes, e2e gates) per the
approved spec `docs/superpowers/specs/2026-07-28-more-page-design.md`.

**Architecture:** A server `page.tsx` (metadata + JsonLd + layout) renders the client
`MoreContent` (useTranslation, like `PublicFAQContent`). Animation is one shared timer-driven
hook (`useLoopedTimeline`) consumed by 26 small scene components built from shared primitives;
a `MoreAnimationContext` + visible pause toggle satisfies WCAG 2.2.2. Data lives in
`more-data.ts` under an anti-regression completeness guard (the `chapters-data` pattern).

**Tech Stack:** Next.js 16 App Router, React 19, Tailwind (theme tokens only), lucide-react,
react-i18next, vitest + RTL, Playwright (+axe).

## Global Constraints

- **NO git actions** (no commit/push — user handles git; overrides the skill's commit steps).
- **No version numbers and no unmanaged numeric claims** in page copy (spec editorial rules).
- **No new dependencies.** CSS transitions/keyframes + staged class toggles only.
- Timers only — **never `animationend`/`transitionend`** (jsdom/React 19 never fires them).
- Every file **< 600 logical SLOC**; theme tokens only (`bg-background`, `text-muted-foreground`,
  `border-border`, `bg-primary/10`, `text-destructive`…) — zero hard-coded colors.
- Scene stages are `aria-hidden`; meaning lives in visible title + description.
- i18n: strict key parity ×6 (en, fr, de, es, it, zh), fr uses U+2019, copy written natively.
  Never interpolate a variable named `count` (triggers plural resolution → zh parity trap);
  use `total`.
- Ratchets are shrink-only: a11y, react-hooks, cc, coverage must not regress.
- Runtime validation happens in the `lia-web-dev` container (docker restart first — no host
  hot reload); never a host `pnpm build`/`pnpm dev`.
- Comments/docstrings in English; page copy in the 6 locales.

**Interfaces (produced):**

```ts
export interface TimelineStep<S> { at: number; state: S }   // at ms from cycle start; steps[0].at === 0
export function useLoopedTimeline<S>(
  steps: readonly TimelineStep<S>[],
  opts: { active: boolean; restMs?: number }                 // restMs default 2500
): S;
// Contract: reduced-motion → always last step's state (resting frame), no timers.
// active=false → freeze on current state, all timers cleared.
// active=true → apply steps at their offsets; after last step + restMs, loop from steps[0].
// Unmount → all timers cleared.

export function MoreAnimationProvider({ children }: { children: ReactNode }): JSX.Element;
export function useMoreAnimation(): { playing: boolean; toggle: () => void };
export function AnimationPauseToggle(): JSX.Element;  // native button, aria-pressed, Pause/Play icon
```
