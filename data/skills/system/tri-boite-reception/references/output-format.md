# Output format — Inbox triage

Headings and words in the user's language. Show only the groups that hold a
message; keep this order.

## 1. Header

📥 Inbox triage — [N] unread messages sorted

When more unread messages remain beyond the page read, add one line: "[N] sorted,
more unread messages remain."

## 2. ✉️ To answer

- **[Sender]** — [subject]
  [what is expected: the question, the request, the deadline]

## 3. 👀 To read

- **[Sender]** — [subject]
  [why it deserves attention]

## 4. ℹ️ For information

- **[Sender]** — [subject] — [one-line gist]

## 5. 🏷️ Promotions and newsletters

[N] messages: [sender], [sender], [sender]

## 6. Next steps

At most three, each one a request the user can make in a few words:
- Reply to [sender] about [subject]
- Archive the promotions
- Read [subject] in full
