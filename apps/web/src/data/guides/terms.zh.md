## 1. 目的

本使用条款（以下简称「条款」）规定了用户（以下简称「用户」）访问和使用 LIA 服务（以下简称「本服务」，网址为 [https://lia.jeyswork.com](https://lia.jeyswork.com)）的方式与条件。

LIA 是一款开源的多智能体人工智能个人助理，旨在帮助用户管理日常数字生活：电子邮件、日历、联系人、任务、笔记、网络搜索等。本服务由一位独立开发者（以下简称「运营方」）开发并运营，不设公司实体。源代码依 AGPL-3.0 许可证发布于 [GitHub](https://github.com/jgouviergmail/LIA-Assistant)。

本条款构成用户与运营方之间具有约束力的协议，其效力优先于任何其他文件。运营方保留随时修改本条款的权利。修改自在本服务上公布之时起生效。任何实质性修改都将通过应用内通知或电子邮件告知用户。

## 2. 条款的接受

访问和使用本服务，以完整且无保留地接受本条款为前提。创建账户或使用本服务，即表示用户确认已阅读、理解并无保留地接受本条款的全部内容。

若用户不接受本条款，则应停止使用本服务。条款修改后继续使用本服务，即视为接受更新后的条款。建议用户定期查阅本条款以了解更新内容。

用户声明其已年满 16 周岁，或已获得法定监护人授权使用本服务。运营方不会在知情的情况下收集 16 周岁以下未成年人的个人数据。

## 3. 注册与用户账户

为访问本服务，用户须提供有效的电子邮件地址和密码以创建账户。用户承诺提供准确且最新的信息，并在信息变更时予以更新。

用户须自行负责其登录凭据的保密。凡通过其账户进行的任何活动，均推定为由该用户实施。如怀疑账户被未经授权使用，用户须立即通知运营方。

本服务可提供通过第三方（Google、Apple、Microsoft）登录的方式。在此情况下，用户授权本服务按其所授予的权限访问其第三方账户的基本信息。用户可随时在账户设置或第三方服务商处撤销该等授权。

每位用户仅可创建一个账户。运营方保留删除重复账户或欺诈账户的权利。

## 4. 服务说明

LIA 是一款多智能体对话式 AI 助理，提供以下能力：

- **邮件管理**：通过 Google Gmail、Microsoft Outlook 与 Apple iCloud 连接器阅读、搜索并撰写邮件。
- **日历管理**：通过 Google Calendar、Microsoft Calendar 与 Apple Calendar 查看、创建并修改日程。
- **联系人管理**：通过 Google Contacts、Microsoft Contacts 与 Apple Contacts 搜索并查看联系人。
- **任务管理**：通过 Google Tasks 与 Microsoft To Do 创建并跟踪任务。
- **网络搜索与浏览**：检索信息、访问网页并提取内容。
- **RAG 空间**：导入并检索个人文档（PDF、文本等）。
- **提醒与计划操作**：创建提醒及周期性自动操作。
- **语音控制**：语音交互（语音识别／语音合成）。
- **MCP 协议**：通过外部 MCP（Model Context Protocol）服务器扩展能力。

本服务使用七家大型语言模型（LLM）提供商生成回答。AI 生成的回答仅供参考，在任何情况下均不构成专业意见（法律、医疗、财务或其他）。

**测试阶段**：本服务目前处于测试阶段，因此免费提供。运营方保留日后推出付费方案的权利，并将事先通知既有用户。测试阶段内，功能可能演进、变更或移除，恕不另行通知。

**HITL（人在回路）机制**：对于敏感操作（发送邮件、修改日程、删除数据），本服务在执行前会请求用户明确批准。用户对以其名义执行的操作保有完全控制权。

运营方承诺依照《通用数据保护条例》（GDPR）及适用的法国数据保护法（Loi Informatique et Libertés）保护用户的个人数据。

**收集的数据**：电子邮件地址、用户名、语言偏好、会话记录、第三方服务（Google、Apple、Microsoft）的连接数据（加密的 OAuth 令牌），以及使用数据（活动日志、性能指标）。

**处理目的**：提供本服务、改进用户体验、保障安全与防范滥用，以及进行匿名化统计分析。

**法律依据**：处理基于用户的同意（GDPR 第 6.1.a 条）以及合同的履行（GDPR 第 6.1.b 条）。

**托管与存储**：数据托管于位于法国及／或欧盟境内的服务器。第三方服务的访问令牌在静态存储时加密（AES-256）。会话内容可能由位于欧盟境外的 LLM 提供商处理（OpenAI、Anthropic、Google、DeepSeek）；在此情形下，相关传输受适当保障措施约束（标准合同条款、充分性认定）。

**保存期限**：数据在账户存续期间保存，并在用户删除账户后的 30 天内删除。

**用户权利**：依据 GDPR，用户享有访问权、更正权、删除权、可携带权、限制处理权与反对权。上述权利可通过应用内所示的电子邮件地址行使，或直接在账户设置中行使。用户亦有权向法国数据保护机构 CNIL 提出投诉。

**LLM 可追溯性**：本服务使用 Langfuse 追踪 LLM 调用，用于排查问题与改进服务。此类追踪记录不含可识别个人身份的数据，且保存期限有限。

更多详情，请参阅我们的隐私政策。

**临时账户与每日清除。** 在此实例上创建的账户为临时账户。所有账户及其数据每晚自动删除，不作个别通知，且无法恢复。不保留任何备份。用户不得在其中存放任何自己无法承受丢失的数据。

**不得托付的数据。** 用户承诺不输入 GDPR 意义上的任何敏感数据（健康、观点、性取向、信仰）、任何商业秘密、任何银行数据、任何凭据或密码，以及任何涉及第三方的个人数据。为生成回答，会话内容将传输至第三方语言模型提供商。

**电子邮件地址与接受条款。** 访问需要有效的电子邮件地址并接受本条款。该地址仅用于激活账户，不作他用；在每日清除时随账户一并消失。不会开展任何营销活动。

**无法连接第三方账户。** 在此实例上，外部账户（Google、Microsoft、Apple 等）的连接在技术上已停用。依赖该功能的特性可见但不可用：这是有意为之，也是演示所要展示的一部分。

**每日容量有限。** 该实例设有每日支出上限。达到上限后，服务将提示在次日之前不可用。访问按先到先得的顺序进行，不设预约、不设排队、不设优先级。
