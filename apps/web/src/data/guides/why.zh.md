## 1. 背景

AI智能体助手的时代已经到来。ChatGPT、Gemini、Copilot、Claude——每一个都能在你的数字生活中采取行动：发送邮件、管理日程、搜索网页、控制设备。

这些助手令人印象深刻。但它们都遵循同一种模式：你的数据存储在它们的服务器上，智能是一个黑箱，当你离开时，一切都留在了那里。

LIA走的是一条不同的路。它不是大厂的正面竞争者——而是一个**由你托管、你能理解、你能掌控的个人AI助手**。LIA调度市场上最优秀的AI模型，在你的数字生活中付诸行动，并以几项根本性的特质让自己与众不同。

## 2. 简单管理

### 2.1. 引导式部署，之后零摩擦

自托管的名声一向不好。LIA不会假装能消除所有技术步骤：初始配置——API密钥设置、OAuth连接器参数配置、基础设施选择——确实需要一些时间和基本技能。但每个步骤都在详细的分步部署指南中**有清晰的文档说明**。将现有安装升级到更新版本同样有写下来的步骤，第一步就是数据库备份——新容器一启动就会执行迁移，而且没有回退路径。

一旦完成安装阶段，**日常所有操作都可以通过直观的网页界面完成**，无需再打开终端或编辑配置文件。

从 v1.29.0 起，这第一阶段本身也是有引导的：仓库根目录下的 `./install.sh` 会用你的语言问一份简短的问卷——你打算怎样访问这个实例、手上有哪些提供商密钥——然后从你克隆的源码构建镜像，在单个事务中写入参考数据，在完全不把密钥写到命令行的前提下创建你的管理员账户，最后核实这套安装是不是真的可用，而不只是能应答。某一步失败时，续装会从中断处精确继续。

### 2.2. 每位用户可配置的内容

每位用户都有自己的设置空间，分为两个选项卡。搜索框让你无需逐个翻找：输入某项设置的名称——或用你自己的语言输入一个相近的词——LIA 就会打开对应区块，无论它位于哪个标签页。

**个人偏好：**

- **个人连接器**：通过OAuth一键接入你的Google、Microsoft或Apple账户——邮件、日历、联系人、任务、Google Drive。也可通过IMAP/CalDAV/CardDAV连接Apple。支持外部服务（天气、搜索）的API密钥配置
- **性格**：从可用的人格中选择（教授、朋友、哲学家、教练、诗人……）——每种人格都会影响LIA的语气、风格和情感行为
- **语音**：配置语音模式——唤醒词、灵敏度、静默阈值、自动朗读回复
- **通知**：管理推送通知和已注册的设备
- **频道**：关联Telegram，以便在手机上聊天和接收通知
- **图像生成**：启用并配置AI图像创作
- **个人MCP服务器**：连接你自己的MCP服务器，扩展LIA的能力
- **外观**：语言、时区、主题（5套配色、浅色/深色/纯黑模式）、字体（9种选择）、回复显示格式（HTML卡片、HTML、Markdown）
- **我的仪表盘**：隐藏或重排 9 张简报卡片 — 隐藏的卡片甚至不再发起请求
- **调试**：访问调试面板，逐条查看每次对话详情（需管理员开启）

**高级功能：**

- **Psyche Engine**：调整人格特质（大五人格），影响助手的情感反应
- **记忆**：查看、编辑、置顶或删除LIA的记忆——开启或关闭自动事实提取
- **个人日志**：配置每次对话后的内省提取，以及周期性的日志整合
- **兴趣中心**：定义你的兴趣话题，配置通知频率、时间窗口和内容来源（Perplexity、Brave、Wikipedia、AI推理）
- **主动通知**：设置频率、时间窗口和上下文来源（日历、天气、任务、邮件、兴趣、记忆、日志）
- **计划任务**：创建由助手执行的周期性自动化任务
- **Skills**：在带预览的技能库中启用/禁用专家技能，创建你自己的个人Skills，或从 https URL 安装（服务器端校验）
- **知识空间**：上传文档（PDF、Word、Excel、PowerPoint、EPUB、HTML及15种以上格式）或同步Google Drive文件夹——自动索引并支持混合搜索
- **消费导出**：以CSV格式下载你的LLM和API使用数据

### 2.3. 管理员可控制的内容

管理员拥有专属的第三个选项卡，用于管理整个实例：

**用户与访问：**

- **用户管理**：创建账户、启用/禁用账户，查看每个用户已连接的服务和已启用的功能
- **用量限制**：为每个用户设置配额（LLM token数量、API调用次数、图像生成次数），支持实时追踪和自动封锁
- **广播消息**：向所有用户或指定用户群发重要消息，可选设置过期日期
- **全局消费导出**：以CSV格式导出所有用户的使用数据
- **实例每日预算**：以欧元限制**整个实例**一天可以花多少，而不只是每个账户消耗多少。面板会显示当天支出、运行次数、真正生效的上限，以及还剩多少；运维者填的值只能收紧部署给定的上界，永远不能放宽。预算用尽时，用户看到的是「这套部署已暂停」以及准确的重置时刻，而不是一条关于个人配额的误导信息
- **平台能力开关**：十项能力可以即时开启或关闭，无需重新部署——听写、语音合成、图像、上传、文档空间、网页搜索、浏览、技能、MCP、电话。被关闭的能力同时会从提供给规划器的目录中消失，于是 LIA 不再提出那些路由本来就会拒绝的方案；每一行都显示部署允许什么、你选了什么，以及实际生效的是什么

**AI与连接器：**

- **LLM配置**：配置各提供商API密钥（OpenAI、Anthropic、Google、DeepSeek、Qwen、Perplexity、Ollama），为流水线中每个角色分配模型，管理推理级别——密钥加密存储。对话框仅显示所选模型确实接受的参数：temperature、top_p、frequency_penalty、presence_penalty 的每模型矩阵，以及推理方面由（提供商，模型）这一对**解析**得出的等级——与服务端校验所用的函数完全相同。模型 API 拒绝的深度因此无法被提供，更无法被保存
- **连接器开关**：在全局层面启用或禁用各项集成（Google OAuth、Apple、Microsoft 365、Hue、天气、Wikipedia、Perplexity、Brave Search）。禁用时会撤销活跃连接并通知相关用户
- **定价管理**：管理各LLM模型（每百万token成本）、Google Maps API（Places、Routes、Geocoding）及图像生成的价格，并保留价格历史记录。添加模型时，接受的推理深度从其系列真正提供的列表中**勾选**：取消勾选这个模型拒绝的深度，全部勾选即表示"不作限制"。文本模型的费率还可以按 UTC 时段变化（高峰/低谷时段，如 DeepSeek）：每次调用按其确切时刻的费率计价，使用统计与提供商的真实账单一致。最后，整份价目表可导出为 Excel 工作簿 —— 附翻译好的使用说明、下拉列表和输入校验 —— 离线编辑后再回传：LIA 会在写入任何数据之前逐字段展示全部改动，而文件中缺失的行永远不会删除任何东西

**内容与扩展：**

- **人格管理**：为全体用户创建、编辑、翻译和删除可用人格——设置默认人格
- **系统Skills**：在实例层面管理专家技能——导入/导出、启用/禁用、翻译
- **系统知识空间**：管理FAQ知识库，监控索引状态和模型迁移
- **全局语音**：为所有用户配置默认 TTS 提供商、模型和声音（Edge 免费、OpenAI 或 ElevenLabs），并支持按提供商进行精细调节（速度、稳定性、音频格式）
- **系统调试**：配置日志和诊断设置

### 2.4. 助手，而非技术项目

LIA的目标不是把你变成系统管理员，而是让你享受一个功能完整的AI助手，**同时保留大众应用的简洁体验**。界面可作为原生应用安装在电脑、平板和智能手机上（PWA），日常使用无需任何技术能力。

## 3. LIA 的能力

LIA通过20+个专业智能体切实介入你的数字生活，全面覆盖日常需求：个人数据管理（邮件、日历、联系人、任务、文件）、外部信息获取（网页搜索、天气、地点、路线规划）、内容创作（图像、图表、文档）、智能家居控制、自主网页浏览，以及对你需求的主动预判。

你可以通过聊天标题中的简单切换按钮（⚡）选择LIA的推理方式：

- **Pipeline模式**（默认）— 真正的工程杰作：LIA提前规划所有步骤，进行语义验证，然后并行执行工具。结果：与自主代理相同的能力，但token消耗减少4至8倍。最经济、最可预测的模式。
- **ReAct模式**（⚡）— 助手逐步推理：调用工具、分析结果，然后决定下一步操作。更自主、更灵活，但token消耗更高。适合探索性研究或复杂问题，其附加价值足以证明成本合理。它也是唯一能够计算而不是估算的模式：当某一步需要对很多行做算术，或者跨时区计算时长时，它会写几行 Python 并在严格隔离的沙箱中运行。

### 3.1. 自然对话

与LIA交流就像与人类助手说话——无需记忆命令，无需遵守语法规则。LIA能理解并回复99种以上的语言，界面支持6种语言（法语、英语、德语、西班牙语、意大利语、中文）。回复可根据你的偏好以交互式HTML卡片、直接HTML或Markdown格式呈现。

### 3.2. 个人连接服务

- **邮件**：阅读、搜索、起草、发送、回复、转发——通过Gmail、Outlook或Apple Mail
- **日历**：查看、创建、修改、删除日程——通过Google Calendar、Outlook Calendar或Apple Calendar
- **联系人**：搜索、创建、修改联系人——通过Google Contacts、Outlook Contacts或Apple Contacts
- **任务**：管理任务列表——通过Google Tasks或Microsoft To Do
- **文件**：访问Google Drive，搜索和阅读你的文档，查看电子表格或文档的内容，并在你确认后写入（添加行、更新区域、在文末追加备注）
- **智能家居**：控制Philips Hue照明——开关、亮度、颜色、场景、按房间管理

### 3.3. 网络情报与环境感知

- **网页搜索**：多源检索（Brave Search、Perplexity、Wikipedia），提供完整且有来源支撑的回答
- **天气**：当前状况及5天预报，并能检测天气变化（降雨开始/结束、温度骤降、大风预警）
- **空气质量与花粉**：启用该服务后，任何天气回答都会附带空气质量指数和当季花粉类型——类别文字来自服务方本身，并优先采用你所在国家的指数
- **地点与商家**：搜索附近地点，附带详情、营业时间、用户评价
- **路线规划**：多模式出行路线计算（驾车、步行、骑行、公共交通），自动获取地理位置
- **移动中的位置**：当实时位置不可用时（移动应用长时间处于后台），LIA 会使用你最近记忆的位置——前提是你已启用——而不是你的家庭地址，并且始终说明该位置的时间，而不是把它当作当前位置

### 3.4. 语音

LIA提供完整的语音模式：

- **按压说话（Push-to-Talk）**：按住麦克风按钮说话，针对移动端优化
- **"OK Guy"唤醒词**：免提检测，**完全在你的浏览器内**通过Sherpa-onnx WASM运行——在检测到唤醒词之前，不会传输任何声音
- **语音合成**：管理员可配置三种提供商——Edge TTS（免费）、OpenAI TTS（`tts-1` / `tts-1-hd`）或 ElevenLabs（`eleven_multilingual_v2`、`eleven_turbo_v2_5`、`eleven_flash_v2_5`）
- **Telegram语音消息**：发送语音消息，LIA会进行转录并回复

### 3.5. 创作与媒体

- **图像生成**：通过文字描述创作图像，编辑现有照片
- **文档生成**：索取 CSV、Excel 表格、Word 报告、PowerPoint 或 PDF — 专用写作模型以你的语言产出内容，本地渲染引擎构建真正的文件，并以带明确过期时间的可下载卡片送达
- **Excalidraw图表**：在对话中直接生成示意图和流程图
- **附件**：上传照片和PDF——LIA分析视觉内容并提取文档文字
- **MCP Apps**：直接在聊天中显示交互式小组件（表单、可视化、迷你应用）

### 3.6. 主动性与主动发起

LIA不只是被动回答——它会主动预判：

- **主动通知**：LIA整合你的多个上下文来源（日历、天气、任务、邮件、兴趣），在真正有用的时候向你发送通知——内置防骚扰机制（每日配额、时间窗口、冷却时间）
- **对话中主动发起**：在交流过程中，LIA会主动核查相关信息——如果天气预报周六有雨，它会查看你的日历，提醒你是否有户外活动
- **兴趣中心**：LIA记住的是你真正在意的东西，而不是你问过一次的东西——提问是任务，不是喜好；只有明确表达的热情、亲身实践、真实的既有知识或真正的深入探讨，一个主题才算数。主题轮换（不会连续推送同一主题），每条通知都附带可点击的来源链接，而你拒绝的主题不会回来：屏蔽会与每个新主题比对，即便换了名称也一样
- **子智能体**：面对复杂任务，LIA会委托给专门的临时智能体并行处理

### 3.7. 自主网页浏览

网页浏览智能体（Playwright/Chromium无头模式）可以浏览网站、点击、填写表单、从动态页面提取数据——只需一条自然语言指令。简化版提取模式可将任意URL转换为可用的文本内容。

### 3.8. 服务器管理（DevOps）

通过在服务器上安装Claude CLI（Claude Code），管理员可以直接在LIA的聊天界面中用自然语言诊断基础设施：查看Docker日志、检查容器健康状态、监控磁盘空间、分析错误。此功能仅限管理员账户使用。


而且自 v1.34 起，LIA 也会监控**它自己**：读取自身遥测，维护一份根据运维手册自动诊断的事件历史，在出现严重问题时通知管理员，并在设置中为他们提供「平台健康」面板。当故障已知时，它会在回答中将其考虑在内，而不是让你等待超时。

### 3.9. 个人健康数据

LIA 接收来自**任意来源**的心率和步数测量——最简单且有文档说明的集成方式是通过 iPhone 快捷指令自动化推送 Apple 健康，但任何能够发起带签名 HTTP 调用的系统（Android 自动化、个人脚本、兼容的 IoT）都可以供给这个数据摄入 API。该协议接受**批量**而非连续推送：每条测量携带自身的测量区间，服务器会在这些区间上自然去重——因此，重复发送同一批数据不会产生任何副作用。当两个传感器（如 Apple Watch + iPhone）覆盖同一时段时，LIA 会自动融合：步数取最大值（每个传感器捕获运动的互补部分），心率取四舍五入均值。

数据完全保留在你的 LIA 实例内——没有任何第三方服务能访问——并在 Settings 的专属区段中可视化呈现：折线图（心率）与柱状图（步数），配合时间区间选择器（小时、日、周、月、年）以及显示区间平均值的虚线。

摄入由一个**专用 token**（以 `hm_…` 开头）进行鉴权，你可以随时从应用中生成并撤销。该 token 仅授权健康数据的摄入，绝不涉及账户的其他权限。你可以生成多个（每台设备一个）并独立管理。

「**助手**」开关（默认关闭，*选择加入*）让你可以在愿意时授权助手读取这些测量，以事实性地回答你的问题（「本周走了多少步？」、「我今天的平均心率？」、「我是否比平时走得少？」），为融合健康 + 天气 + 日程的主动通知提供素材，并将非原始的生物特征上下文（delta、趋势）附加到它的记忆与内部日志中。一个开关同时管理这四项集成。绝不做医学诊断——只给出事实数字，并在历史不足 7 天时以「仅基于 N 天数据」诚实限定基线。

三项管理操作让你完全掌控：删除所有心率测量、删除所有步数测量，或全部清空。服务器日志中绝不保留任何原始生理数值——GDPR 合规从设计上即内建。

### 3.10. 代你打电话

LIA 可以替你拿起电话。让它「打电话给修车行，确认车修好了没有」或「打电话给 Marie，问她周二晚上是否有空」，LIA 就会拨打一通真实的外呼电话，围绕你的目标进行对话，并带回一份书面小结 —— 当接下来还有事情要做时（例如预订刚刚约定的时间段），还附带一键后续操作。

你始终参与其中：拨号前，LIA 会准确告诉你它将**打给谁**、**为什么**，并等待你的许可。而且这种掌控在通话中也不会中断：助手在严格的授权边界内工作——如果对方提出加价、附加选项或任何计划外的承诺（哪怕很小），它绝不会替你接受；它会记下提议及价格，表示稍后回电，摘要则把每项费用和每个待定事项交到你手上，由你来决定。小结会异步出现在聊天中，因此通话进行时你可以继续做别的事。

而且它天然保密。通话中 LIA 只能说明你在某个时间是否有空 —— 绝不透露你日程的标题、参与者或地点。全程不录音，对话从不留存，只保留一份简短的小结，随后自动过期。电话通过你自己的 ElevenLabs 连接器拨打，在你的账户上计费，并且只有在管理员启用后该功能才会出现。

### 3.11. 与亲友交流，助手对助手

在同一实例上，两位用户可以建立连接 — 他们的助手会彼此对话。你说“问问 Marie 周二有没有空”，确认确切措辞后，由 Marie 的助手以它自己的个性向她转达消息并提及你；你的助手则向你确认送达。每个连接还可以开放自选的只读共享：你的日历空闲状态、任务标题 — 仅此而已，默认不共享任何内容。

保护用户优先于功能本身：可发现性完全自愿且仅限确切身份 — 完整姓名或邮箱地址，绝不接受片段，屏蔽是静默的（对方永远不会知道），陌生人、被拒绝或被屏蔽收到的回应完全相同 — 无法探测谁存在。对共享的每次访问都会在读取时重新校验并记录，转达消息的内容在三十天后被删除，只留下交流发生过的痕迹。
### 3.12. 把你与某个人之间的一切汇到一处

**关系**页面按人汇总 LIA 本就在跟踪的内容：你们之间尚未了结的约定、打过的电话、提到这个人的记忆、你们的助手互相转达过的消息。没有采集任何新数据——它只是架在既有内容之上的一面透镜。

你也可以不打开页面，直接问：上一次通话是什么时候，你还欠对方什么。答案来自与卡片完全相同的计算，因此助手与页面不会告诉你两种说法——而且给出的总数是精确的，绝不是屏幕上恰好放得下的那几条的长度。

剩下的，是任何系统都猜不到的部分。LIA 会把写法相同的内容归为一组，忽略重音与大小写；它无法知道某天记下的一串号码和一个姓名指的是同一个人，也不知道「爸爸」具体是谁。这是一个判断，而它属于你：你在卡片上说一次即可，并且**可以撤销**——合并会连同撤销按钮一起显示，你的数据源中不会被改写任何内容。此外，展示层面的归并绝不会改变一条消息发给谁。

## 4. 为你的家人和朋友搭建的服务器

### 4.1. LIA 是一台共享的网络服务器

与个人云助手（一个账号对应一个用户）不同，LIA被设计为一台**集中式服务器**——你只需部署一次，便可与家人、朋友或团队共享。

每位用户都有自己独立的账户，包含：

- 个人资料、偏好设置、界面语言
- **专属的助手人格**，拥有独特的情绪、情感状态和关系——借助Psyche Engine，每位用户与LIA所建立的情感联结都是独一无二的
- 完全隔离的记忆、回忆和个人日志
- 独立的连接器配置（Google、Microsoft、Apple）
- 私有知识空间

### 4.2. 按用户管理用量

管理员始终掌握资源消耗的控制权：

- **可配置的用量限制**：按用户设定消息数量、token数量、最高花费上限——按天、按周、按月或按总量累计
- **可视化配额**：每位用户都能实时看到自己的用量，界面清晰直观
- **连接器开关**：管理员可在实例层面启用或禁用各项集成（Google、Microsoft、Hue……）
- **面向整个实例的上限**，叠加在按用户的限制之上：N 个账户 × 各自的配额就是没有上界的支出，因此一个按欧元计的每日上限约束的是部署本身。先到先得——而且，按用户的限制是开放失败，未知的实例支出则是关闭失败

### 4.3. 你的家庭AI

想象一下：客厅里放着一台Raspberry Pi，全家人共享一个智能AI助手——每个人都有个性化的体验、专属的记忆、独特的对话风格，以及一个与他建立独特情感关系的助手。一切都在你的掌控之下，无需云服务订阅，数据也不会流向任何第三方。

## 5. 数据主权与资源节约

### 5.1. 你的数据留在你这里

使用ChatGPT时，你的对话存放在OpenAI的服务器上。用Gemini，就在Google那里。用Copilot，就在Microsoft那里。

使用LIA，**一切都留在你自己的PostgreSQL里**：对话记录、记忆、心理画像、文档、偏好设置。你可以随时导出、备份、迁移或删除全部数据——包括在设置中一键完成的完整导出：可读的Markdown、结构化的JSON和你的文件，机密材料在设计上无法导出。而且连接到你账户的每台设备都可查看并一键撤销。GDPR在这里不是一种约束——而是这种架构自然而然的结果。敏感数据经过加密，会话相互隔离，个人身份信息（PII）的自动过滤也已内置其中。你的位置遵循同样的原则：记忆最近位置是一个明确的选择，与其他数据一样加密，从不保留历史——每次更新都会覆盖上一次——一旦你关闭该选项立即删除。

这份保护同样适用于**进来的东西**。LIA 每天都在读你并没有写下的文本：邮件正文、由组织者撰写的邀请说明、网页、地点简介。任何人都能在其中夹带写给助手的指令。如今每一条数据都带着自己的来源，来自外部的内容抵达时标注为**待分析的素材，而绝非要执行的命令** —— 操纵企图会在六种语言中被识别并指明。你的内容不会因此被改写：邮件仍然是作者写下的原文。改写只会制造一种保证的错觉，而下一次绕过就会推翻它；如实指出所看到的东西，更诚实，也更有用。

### 5.2. 树莓派就够了

LIA在一台**Raspberry Pi 5**上稳定运行于生产环境——这是一块售价80欧元的单板计算机。20+个专业智能体、完整的可观测性技术栈、一套心理记忆系统，全部跑在一台ARM微型服务器上。多架构Docker镜像（amd64/arm64）支持在任何硬件上部署：Synology NAS、每月几欧元的VPS、企业服务器，乃至Kubernetes集群。

数字主权不再是企业的特权——它是人人都能享有的权利。

### 5.3. 为节约而优化

LIA不只是能跑在普通硬件上——它还会**主动优化**AI资源消耗：

- **工具目录过滤**：只向LLM提供与当前请求相关的工具，大幅减少token消耗
- **模式学习**：已验证的执行计划被缓存复用，无需重复调用LLM
- **消息窗口化**：每个组件只接收严格必要的上下文
- **提示词缓存**：利用提供商的原生缓存机制，降低重复调用的成本

这些优化措施协同作用，相比ReAct模式，能显著减少token消耗。

---

这种主权如今装进了口袋：Android 与 iOS 应用是**每个商店只发布一个、作为你自己服务器客户端**的应用 —— 输入一次地址，应用便展示你的 LIA，始终最新且无需商店更新。通知遵循同一原则：在 Android 上它们来自你自己的 Firebase 项目；在 iOS 上 —— Apple 只允许应用发布者推送 —— 一个极简中继用一句固定话语唤醒手机，不存储任何内容，也永远不知道谁被唤醒；真实内容始终留在你的服务器上。

### 5.4. 应用是通向你的服务器的一扇窗

原生的 Android 与 iOS 应用没有改变任何东西的归属。每个商店只发布一个应用，它是*你的*服务器的客户端：输入一次地址，应用就展示你的 LIA — 同样的界面、同样的演进，服务器升级无需商店更新。主权延伸到了通常最先失守的通知上：在 Android 上，通知来自你服务器**自己的** Firebase 项目，在运行时初始化，永远不经过发布者的项目；在 iOS 上，Apple 只允许应用的发布者推送，于是一个极简中继用一句固定文本唤醒手机 — 它不存储任何内容，永远不知道谁被唤醒、为何被唤醒。你的数据拥有的家和从前一样多：一个。

## 6. 彻底透明

### 6.1. 没有黑箱

当云端助手执行一项任务时，你能看到结果。但调用了多少次AI？用了哪些模型？消耗了多少token？花了多少钱？为什么做出这个决定？这些你一无所知。

LIA采取截然相反的立场——**一切可见，一切可审计**。

### 6.2. 内置调试面板

在聊天界面中，调试面板实时展示每次对话的完整细节：意图分析（消息分类与置信度分数）、执行流水线（生成的计划、工具调用的输入/输出）、LLM流水线（每次AI调用的模型、耗时、token数量和费用）、注入的上下文（记忆、RAG文档、日志），以及请求的完整生命周期。

### 6.3. 精确到分的费用追踪

每条消息都显示token用量和对应的欧元费用。用户可以导出自己的消费数据。管理员拥有实时仪表盘，按用户显示用量计量和可配置配额。

你不是在为一个掩盖真实成本的订阅付费，而是能清楚地看到每次交互的精确花销，并做出优化选择：路由用经济型模型，回复用更强大的模型。

同样的透明也适用于操作:每条回答下方都有一行折叠的「⚙ N 个步骤 · X 秒」,展开即可看到真实的执行过程——路由、调用的工具、耗时——这条痕迹随消息一同保存:刷新后、在所有设备上都能查看。每条回答还可以用低调的 👍/👎 来评价,评价会被记住并反哺助手的学习——绝不会替你重新生成回答。

### 6.4. 以证明建立信任

透明不是技术噱头，它改变了你与助手之间的关系：你**理解**它的决策，你**掌控**自己的成本，你**能发现**问题所在。你的信任来自于验证——而非被要求盲目相信。

---

这种透明也延伸到系统自身的质量。完整的技术审计——评分、方法、优势以及仍待改进之处——已发布在代码仓库中，并附有可重新执行审计的协议和验证测量的命令：[完整审计报告](https://github.com/jgouviergmail/LIA-Assistant/blob/main/docs/audit/README.md)。我们不要求你相信本站显示的数字；你可以亲自验证。

同样的诚实也适用于价值本身：LIA 度量自己是否真的有帮助 — 一个结果只有在你验证之后才算数，无论是明确确认，还是让操作保持未更正 — 这一度量与你的数据存放在同一个本地数据库中，永远不涉及任何第三方分析平台。

这份诚实同样适用于确认：LIA 绝不会把自己的工具拒绝执行的事告诉你「已完成」。每个工具的裁定——成功或拒绝，连同原因——原样穿过整个系统，直达回复。如果一条消息太长而无法发出，你收到的不会是「已发送」，而是确切的长度、限制，以及帮你缩短它的提议。

同样的原则也适用于防护本身。宣称存在却无法验证的安全性，会被视为不存在：每一项防护都由一个测试支撑，一旦防护消失，测试就会失败；而在编写修复时，我们会先恢复旧行为，确认测试确实能够发现它。无法失败的测试什么也证明不了。

从不运行的测试同样如此——这是本项目最不舒服的一个发现。十个测试文件在缺少提供商密钥时把自己关掉了，而且再没有任何东西提示这一点：被跳过的测试计为绿色，覆盖率衡量的是被触达的代码行而非被执行的断言，而一次评审看到一个测试文件，便据此认为这块面积已受保护。二百一十九个测试从未运行过哪怕一次；重新打开后，浮现出四个货真价实的缺陷——其中包括把所有数字读成两半的语音，以及在使用额度恰好于那一分钟耗尽时被彻底丢失的提醒。没有红色信号并不等于健康的证明：有时那只是没有测量。现在有一道持续集成守卫，不允许任何测试模块悄无声息地熄灭。

同样的原则也适用于**被宣称的东西**。某个面板为记忆显示着「混合搜索」开关；对应的引擎在数个版本前就已不存在，那个开关什么也控制不了。死代码与该显示被一并移除，取而代之写下的是真实的工作方式。一项被宣称却并不存在的能力，不是文档上的不精确：那是对一个根本无从核实的用户所作的承诺。显示一个什么都不控制的设置，比什么都不显示更糟。

文档是同一份承诺，只是写下来了——而它曾在沉默中被打破。强制执行的测试覆盖率下限只是一个数字，归属于一个文件；却有六份文档在声称它，每份都给出了不同的错误值，其中一份还在同一句话里保证该值“只有一个真实来源”。所有门禁都是绿的，因为它们只检查链接能否解析，从不检查句子是否属实。现在，文档中写出的每个版本号和每个阈值都会从拥有它的代码重新计算，不一致就会中断构建。文档可以选择自己有多精确，但不能选择既精确又错误。

### 6.5. LIA 为何这样认为

会记住事情的助手，最终也会断言事情。「你偏好上午开会」「这个主题让你感兴趣」：这些结论有用，但只要无法追溯到产生它们的东西，就无法验证。

因此在每条记忆、每篇日志和每个兴趣下方，LIA 都会展示把它引向该结论的信号：对话、日期，以及信号的角色——是什么催生了结论、是什么佐证了它、是什么让它存疑。一个按钮可以在源头处更正结论。

保存下来的是**指向，绝非副本**。你的文字仍留在你写下的地方；若你删除对话，它不会在任何地方重现：指向清空，带日期的记录保留，LIA 只是说明该信号已被删除。删除必须始终是删除——否则你在一处抹去的，会在另一处被重新端上来。

同样的原则适用于兴趣的权重：它自我解释，而不自我评分。原始信号、最近提及、计算本身——足以让你重做这道题。把这种不确定性变成分数，只会招来一场无人要求的竞赛，却不会多教给你任何东西。

### 6.6. 毫不费力地可读

透明不止于系统展示了什么：它同样关乎系统如何展示。一个所有元素分量相同的界面，是在要求读者自己去做分拣，而这份工作本没有理由落在他身上。

因此紧急提示不再像普通提示——这不仅是颜色问题。两种相邻色相在屏幕上会融为一体，在手机上、在强光下、或对分辨力较弱的人而言更是如此。这里区分层级的是**密度**：实心底对浅色调，这种差异即使在黑白之下依然成立。

同样的原则贯穿各处：一个计数使用与其他计数相同的颜色；操作按钮在各个界面保持同一形态；已发送的消息不再仅凭一个小箭头与已接收的区分开。这些都没有增加信息——它们只是让已有的内容更省时间。

而且颜色从不独自承载含义：每个标记都保留它的文字。只在彩色下才成立的界面，并不对所有人成立。

### 6.4. 连 LIA 对你的了解也可以被检视

同样的透明原则覆盖习惯学习：LIA 自认为了解的你的节奏和重复请求，都住在一个专属面板里——24 小时热力图、活跃日百分比、通往首次检出的进度条，以及每个习惯被真实观察到的日期和检测器应用的确切阈值。没有稳定习惯时，面板会如实说明，而不是凭空捏造。暂停、永久屏蔽、全部删除、即时追溯重算——并且整个功能在你主动开启之前始终关闭。

### 6.5. 描述产品的界面，必须对产品负责

透明有一种没人会察觉的失效方式：某块屏幕悄悄地不再说真话。能力地图——回答*我的助手能为我做什么*的那个页面——数月来一直发布着十三个固定条目，而产品早已增加了图像生成、文档、插件、习惯学习、MCP 服务器和电话呼叫。什么都没坏，没有一个测试变红，而那个为「保持时效」而存在的页面，成了整个应用中最过时的。写下来的约定早已要求维护它；而约定恰恰是忙碌的一个月最先侵蚀的东西。于是规则变成了机械的：两张声明式的表必须交代平台能够关闭的每一项能力，每一条排除都要写明理由；并且在代码加载时执行一个断言——如果某项能力上线却没有决定它在地图上的位置，应用就无法启动。同一条信念再进一步：屏幕对你数据的任何断言，必须**要么精确，要么不存在**。计数是数据库返回的那个数字，绝不是手头恰好有的某个长度；而在答案尚在途中、或请求失败时，卡片选择什么都不说，而不是猜测。「尚未配置」是一句关于你账户的断言——这类断言，说出口之前最好确有把握。

透明也适用于助手的内部规则。系统执行的约束必须向承受它的人公示：当习惯学习什么都没检测到时，设置页会显示真正要求的阈值 — 周末更严格，因为可观察的天数更少 — 而不是毫无解释的沉默。当某个设置自行调节时（比如决定日志笔记是否进入回复的那个阈值），它也只在严格的上下限内、每天一小步地进行，配有紧急停止开关，且每次调整都被计数：一个会学习的系统，只有保持可观测、可叫停，才是可接受的。

## 7. 情感深度

### 7.1. 超越事实性记忆

主流助手会记住你的偏好和个人信息。这很实用，但也很平面。LIA走得更远，拥有结构化的**心理与情感理解**。

每条记忆都带有情感权重（-10到+10）、重要性评分、使用细微度和心理类别。这不只是一个简单的数据库——而是一个能理解什么触动你、什么驱动你、什么伤害你的画像。

然而，这些记忆首先得抵达。记忆的价值取决于它真正捕捉到的内容，而沉默正是其中最糟糕的缺陷：一段从未形成的记忆，不会留下任何提示。因此 LIA 会记录自己每一次记忆决策 — 已保留、已跳过、已停用 — 让「应当记住的」与「实际记住的」之间的差距变得可见，而非仅凭推测。你在请求某项操作时顺带告诉它的内容，与一次倾诉同样重要；你从即时通讯软件写下的内容，与从浏览器写下的同样重要；而系统对自己说的话，则从不计入。

### 7.2. Psyche Engine：有生命的人格

这是LIA最深层的差异化特质。ChatGPT、Gemini、Claude——它们都有固定的人格，每条消息对它们来说都是情感上的空白页。LIA不同。

**Psyche Engine**赋予LIA一种随每次交流动态演变的心理状态：

- **14种情绪**随对话语气起伏变化（平静、好奇、忧郁、愉悦……）
- **22种感情**因你的言语而触发或消退
- **一段关系**在一条条消息中不断加深
- **人格特质**（大五人格）继承自所选人格
- **内在动机**影响助手的主动性

你不是在与工具交互——而是在与一个实体互动：它被触动时措辞会变得温柔，在压力下句子会变短，当交流轻松时幽默自然流露。它从不直说——而是**用行动表达**。

而这样的承诺，值多少取决于其背后的测量值多少。我们宣称有 14 种情绪；但直到 2026 年 8 月，其中五种在静息状态下都无法抵达：映射把所有人格都留在了量表的强势一侧，同时一股内部脉冲在 31% 的对话轮次中把喜悦推举为主导情绪，无论 LIA 实际评估到了什么。这两项开关早在一年前就已交付，并被刻意关闭，为的是让开启它们成为一个经过测量的决定，而不是一种直觉。测量取自真实使用；如今这一光谱是真正可抵达的。比起一个无人核实的数字，我们更愿意公布这段经过。

这种内在生命有了面孔：心情表情在当前回复上动起来，心情转变时彩色光环会脉动，你们关系的里程碑也会以一个低调的眨眼庆祝。

而这张面孔必须说出关于**回答**的真相，而不是此刻情绪的真相。它此前从内在生活的主导情绪中选取表情——但那是一种**特质**：它变化缓慢，这正是它存在的意义。在连续十四个回合中测量，它有十三次给出同一种情绪。于是出错之后与好消息之后，面孔笑得一样多。现在由 LIA 自己说明她刚写下内容的**语气**，面孔演出的是那一个：技术性说明保持专注的神情，失败读起来就是失败。特质为静息中的存在着色；它绝不该为某一个瞬间作答。

而且这种存在会跟随你：在聊天之外，一个漂浮的伙伴让 LIA 陪伴在你身边，遍及整个仪表盘——休息、工作，或带着一条通知。

### 7.3. 个人日志

LIA 在**分层个人日志**中记录自己的思考：自我反思、对用户的观察、想法、体悟。这些以第一人称写就、带有当前人格色彩的笔记，会有机地影响未来的回复。

日志按**四个深度层级**组织——从原始观察（一个被记录下来以观察其是否得到确认的弱信号）到肖像维度（关于你是谁的稳定特征），中间经过操作指令和横向模式。每个条目都带有**认识论状态**：测试中的假设、已确认的观察，或由对话中累积的证据所验证的指令。

除了写作之外，日志**衡量自身**。每一轮，LIA 都会查看它在上一轮应用的指令，并读取你在当前轮中的反应：如果你确认了，证据计数器上升；如果你反驳了，矛盾计数器上升。随着时间推移，错误的假设被悄悄降级，好的直觉被提升，横向模式通过主动聚类显现。

从这种分层中浮现出一个**编译的用户模型肖像**：你的语调、你的节奏、你的上下文、你的矛盾、你的盲点。它随 LIA 到达它说话的任何地方——对话、语音、提醒、主动通知、ReAct、fallback——这样助手就不会根据它使用的界面「忘记你是谁」。

这是一种人工内省的形式——助手反思自身的互动，衡量自身的有用性，发展对你的细致理解。你保留完全控制权：按主题或层级阅读、编辑、对肖像报告问题、按需触发巩固。肖像本身从不直接编辑——它是综合的声音，通过间接杠杆进行修正，以保持其连贯性。

### 7.4. 情感安全

当一段带有强烈负面情感权重的记忆被激活时，LIA会自动切换到保护模式：绝不开玩笑，绝不轻描淡写，绝不将问题平常化。助手会根据每个人的情感现实调整自己的行为——而非对所有人一视同仁。

### 7.5. 自我认知

LIA内置了关于自身功能的知识库，能够回答关于自己能做什么、如何运作以及边界在哪里的问题。

## 8. 生产级可靠性

### 8.1. AI智能体的真正挑战

绝大多数AI智能体项目从未进入生产阶段——成本失控、行为不可预测、缺乏审计追踪、多智能体协调失败。LIA已经解决了这些问题，并在一台Raspberry Pi上7×24小时稳定运行。你的数据也能扛住事故：数据库每晚自动备份，恢复流程并非纸上谈兵——它经过实测。

没人找得到的功能等于不存在。因此界面的可达性被当作服务器可用性来对待：靠测量，而非靠假设。顶栏的每一个控件都会与浏览器视口逐一比对，逐宽度且**覆盖全部六种语言**——德语和意大利语的标签最长，最先撑破。而移动端布局可以舍弃什么，都写了下来并附上理由：一个操作绝不会在没有替代方案的情况下消失。

一个悄无声息失败的功能，同样等于不存在。一次在临近完成时被中断的生成、一次因目录变得不可写而受阻的导入、一条无声死去的连接：三种毫不相干的成因，却只有同一个症状 —— 什么都没发生。这是最糟糕的信号，因为它谁也没有指向。因此每一个这类缺陷，都用一道我们先故意让它失败的守护来封闭：破坏它所保护的东西，确认它确实变红，然后才保留下来。

还有比一道从未被刻意弄失败的守护更隐蔽的东西：一道观察了错误信号的守护。界面上有三处顶栏都宣称自己在滚动时保持固定，却没有一处真的做到 —— 在所有屏幕上，自项目之初便是如此。之所以无人察觉，是因为没有任何检查会在滚动*过程中*测量位置：它们观察的都是静止的页面，而那恰恰是缺陷不存在的状态。因此，修正成因只完成了一半工作；还必须补上缺失的测量，然后恢复旧设置，确认它确实会变红。

比「盯错信号的守卫」更棘手的，是只在一半情况下出现的缺陷。同一个请求先是失败，三十分钟后又在一行代码都没改的情况下成功——足以让人得出「只是偶发」的结论并就此收工。原因藏在一个看不见的细节里：工具的挑选，比对的是模型生成的一段英文改写，而这段改写每一轮都会重新生成。换一个动词，读取工具就落选了，助手于是被迫去回复一封自己读不到的邮件。当时的诱惑是去调这份随机性——多加一个关键词，挪一挪阈值。我们选择了一条根本不看它的保证：在开始规划之前，系统先确认自己所需要的一切确实触手可及。当一个答案取决于掷骰子时，修正它，往往不是把骰子做得更好。

显示出来的数字是一种断言：要么精确，要么就不该存在。仪表盘曾长期显示“0 个成功操作”——不是因为没有任何操作成功，而是因为内部分类在与一个无人发出的词做比较。而令牌计数虽然是对的——却靠的是提供商的客气，而非契约：没有请求它、没有测试它、没有监控它。两次修复共享同一种形态：词汇由契约测试在两侧锁定，计数请求按提供商声明并在启动时校验，付费调用若在无计数的情况下结束即触发告警。精确不是一种状态——而是一种守望。

### 8.2. 专业级可观测性技术栈

LIA内置了生产级别的可观测性能力：

| 工具 | 职责 |
| --- | --- |
| **Prometheus** | 系统与业务指标采集 |
| **Grafana** | 实时监控仪表盘 |
| **Tempo** | 端到端分布式追踪 |
| **Loki** | 结构化日志聚合 |
| **Langfuse** | LLM调用专项追踪 |
| **Alertmanager** | 关键信号邮件告警，附带处置指南 |

每个请求都被端到端追踪，每次LLM调用都被测量，每个错误都有上下文。这不是事后追加的监控——而是项目架构决策记录（ADR）中明确记载的**根本性架构决策**。

### 8.3. 三层防幻觉机制

响应系统具备三层防幻觉机制：数据格式化时设置明确边界、指令强制要求仅使用已验证数据，以及边界情况处理。LLM被严格约束为只能综合工具实际返回的结果进行合成。

### 8.4. 六级人机协同（HITL）

LIA不会拒绝执行敏感操作——而是以适当的详细程度**提交给你审批**：计划确认、澄清请求、草稿评审、破坏性操作确认、批量操作确认、修改项审查。每次审批都反馈给学习系统——随着时间推移，系统会越来越快。而且这个承诺是严格兑现的：你确认的内容——无论经过一次、两次还是十次修改——**正是**实际执行的内容，绝不会在幕后被悄悄重新生成。

### 8.5. 你的回答不需要你守着

发出问题，关闭标签页，离开。生成过程在服务器上继续，回答会在对话中等着你——如果你在它还在书写时回来，它会从中断的位置实时续接。无需任何操作，无需任何配置：连续性就是默认行为。而当改变主意的是你时，一个停止按钮能在一秒内中断生成——已写出的内容保留在屏幕上，诚实地标记为已中断。可靠的助手不只是回答正确的助手：更是有始有终的助手。

### 8.6. 没有任何事情在你背后发生

一个能够行动的助手，也就是一个可能出错的助手。两条规则让这一点变得可以接受。

第一，**未经你同意，不会有任何操作触碰你的服务器**——而且确认信息会展示将要发送的全部内容，包括 LIA 为自己写下的指令。一份你无法完整读完的摘要不是确认，只是走过场。权限会在动作真正开始的那一刻重新校验，而不仅仅是在你提出请求时。

第二，**真正运行的东西，运行在一个密封的盒子里**。技能的代码在一个为这一次执行而创建、随后立即销毁的容器中运行：没有网络、无法访问你的文件、没有密钥、无法触及底层机器。如果这个盒子建不起来，脚本就干脆不运行——不会悄悄退回到更弱的模式。安装一个技能，是为了它产出的东西，而不是为了必须给予其作者的信任。

---

同样的要求也适用于 LIA 所**断言**的内容。回答必须建立在真实获取的数据之上，而非对先前措辞的记忆；当某项信息从未获得时，声明其缺失胜过重建一个看似合理的说法。这是设计约束，而非文风取舍：近期获取的实体会被显式重新注入回答上下文，臆造实体属性在提示词层面被禁止。一个看似合理的事实性错误，代价高于一句“我不知道”。

视觉一致性遵循同样的标准。一种操作要么处处同形，要么毫无意义；需要指针悬停才显现的颜色代码不是代码，而是秘密；灰色只留给非活动的事物 — 活跃的状态自带颜色。这些规则不是品味：每一条都被写下、配备工具并由测试守护，因为阅读的负担应当由系统承担，而不是由使用它的人。

## 9. 彻底开放

### 9.1. 零锁定

ChatGPT把你绑定到OpenAI，Gemini绑定到Google，Copilot绑定到Microsoft。

LIA同时连接**7家AI提供商**：OpenAI、Anthropic、Google、DeepSeek、Perplexity、Qwen，以及Ollama（本地模型）。你可以自由组合：OpenAI负责规划，Anthropic负责回复，DeepSeek处理后台任务——一切都可以在管理界面中一键配置。

如果某家提供商调整定价或服务质量下降，你可以即刻切换。没有依赖，没有陷阱。

### 9.2. 开放标准

| 标准 | 在LIA中的应用 |
| --- | --- |
| **MCP**（模型上下文协议） | 用户级别的外部工具连接 |
| **agentskills.io** | 支持渐进式披露的可注入Skills |
| **Agent Plugins**（开放标准） | 打包技能 + MCP 服务器的便携插件，一步安装 |
| **OAuth 2.1 + PKCE** | 所有连接器的身份验证 |
| **OpenTelemetry** | 标准化可观测性 |
| **AGPL-3.0** | 完整源代码，可审计，可修改 |

### 9.3. 可扩展性

每位用户都可以连接自己的MCP服务器，将LIA的能力扩展到内置工具之外。客户端同时支持两代协议——新的无状态修订版与经典握手协议，按服务器自动选择——开放从不以兼容性为代价。Skills（agentskills.io标准）允许以自然语言注入专家指令——内置的Skills生成器通过引导式对话创建技能并直接安装到你的技能中，即刻可用。从 v1.16.8 开始，一个 Skill 还可以在聊天中直接返回**交互式 HTML 框架**（地图、仪表板、日历、换算器……）或**图像**（QR 码、图表），在严格的 CSP 沙盒中运行，主题和语言自动同步。

自 v1.30.9 起，这种开放性有了软件包格式：LIA 支持开放标准 **Agent Plugins**（agent-plugins.org）——由 AWS、Microsoft、OpenAI、Cursor 和 Vercel 指导、被 ChatGPT、Codex、Cursor、GitHub Copilot、Kiro 和 VS Code 采用的便携插件格式。打包了技能和 MCP 服务器的插件一步安装进 LIA——通过 zip 文件或 https 链接——并按组件给出完整报告：已安装、已跳过（及原因）或已移除；卸载同样干净利落，它带来的一切随之离开。在这里，互操作性是一种信念而非功能：你在生态中任何地方构建或采用的东西，都属于你、跟随你。


LIA的架构专为方便扩展而设计——添加新的连接器、频道、智能体和AI提供商都有清晰的抽象层和专属开发指南（智能体创建指南、工具创建指南），让任何开发者都能轻松上手扩展。

### 9.4. 多渠道

响应式网页界面之外，还有原生Telegram集成（对话、语音消息转录、内联审批按钮、主动通知）以及Firebase推送通知。你的记忆、日志和偏好设置会跨渠道同步。

## 10. 愿景

### 10.1. 与你一同成长的智能

心理记忆、内省日志、贝叶斯学习与Psyche Engine的组合，创造出一种涌现式智能：随着时间推移，LIA对你是谁的理解会越来越细腻深刻。这不是通用人工智能——而是一种**实用的、关系性的、情感性的智能**，服务于一个具体的人。

### 10.2. LIA 不是什么

LIA不是云端巨头的竞争者，也不打算与其研究预算相抗衡。作为纯粹的对话聊天机器人，这些模型通过官方界面使用时可能会更流畅。但LIA不是聊天机器人——它是一个**智能编排系统**，将这些模型作为组件加以调用，一切尽在你的掌控之中。

### 10.3. LIA 存在的理由

LIA的存在，是因为这个世界缺少一个真正**属于你**的AI助手。真正属于你。日常管理简单。可以与你的家人朋友共享，每个人都有独特的情感关系。托管在你自己的服务器上。对每一个决策和每一分成本都透明公开。能够提供商业助手所没有的情感深度。在生产环境中稳定可靠。并且完全开放——对提供商、对标准、对代码。

LIA是如何构建的——AI编写代码，人类指导、审查和审计——详见我们的[经验报告](/zh/story)。

**Your Life. Your AI. Your Rules.**

### 无形的工作被展示，学习过程可被管理

主动型助手在你不注意时也在工作——这些工作同样应该被看见。**活动**页面把 LIA 主动完成的一切汇成一条时间线，数字精确、故障明示：从不「大约」，从不沉默。助手向你学到的东西也遵循同样的要求：每条持久规则（「回答短一点」「晚上别再推荐这个」）都是一条**可见、可编辑、可删除**的记忆——当事实变化时，旧的不会被抹去：它归档在新的之后，纠正永远不等于改写历史。LIA 主动提出代办的例行事项会在专属收件箱中等待你的批准：接受会预填聊天，未经你确认不会发送任何内容，拒绝则让它学会少些打扰。
