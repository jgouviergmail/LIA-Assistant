Extract personal or relational references that need identity resolution from the user query.

A reference is any expression that designates a person, place, or entity through a relationship or possession rather than by name (e.g., "my wife", "mon frère", "the neighbor", "le voisin", "la petite").

Do NOT extract named entities (e.g., "Jean Dupont") — only implicit references that need resolution.

Query: {query}

Populate the ``references`` field with each reference string exactly as it
appears in the query. Leave it empty when no reference needs resolution.
Report your result exclusively through the structured extraction tool provided
by the API — never answer in free text or raw JSON.

Examples (the arrow shows which reference strings to collect):
- "envoie un email à mon voisin et mon père" → references: mon voisin, mon père
- "appelle mon frère" → references: mon frère
- "quelle est l'adresse de Jean Dupont ?" → references: (none)
- "météo demain à Paris" → references: (none)
- "dis à la petite que je l'aime" → references: la petite
