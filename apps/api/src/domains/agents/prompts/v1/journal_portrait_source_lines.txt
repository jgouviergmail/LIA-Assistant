# One-line scaffolds of the consolidation prompt's INPUT sections, `key|template`
# per line; blank lines and #-comments are ignored (ADR-284: prose never lives
# in a .py). Labels and lines only — the instruction on how to USE a section is
# STEP 7's, one instruction per context.
#
# The portrait sources (2026-09-16 design, part B; nine since 2026-10-12) are
# rendered by their owning domain (memories, interests, habits,
# relations/debrief, open_loops, workboard, scheduled_actions, reminders,
# bookmarks), each reading only its own keys; the usage-pattern and health
# blocks were the last two scaffolds written inline in the service and moved
# here unchanged. Every item is rendered WHOLE: a line is one item.
