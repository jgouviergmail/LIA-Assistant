# per line; blank lines and #-comments are ignored (ADR-284: prose never lives
# in a .py). Labels and lines only — the instruction on how to USE a section is
# STEP 7's, one instruction per context.

# The four portrait sources (2026-09-16 design, part B) are rendered by their
# owning domain (memories, interests, habits, relations/debrief), each reading
# only its own keys; the usage-pattern and health blocks were the last two
# scaffolds written inline in the service and moved here unchanged.
