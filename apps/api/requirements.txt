# urllib3-future (transitive: caldav -> niquests) ships a wheel that CLOBBERS
# the genuine urllib3/ package plus a .pth that re-clobbers it at every
# interpreter start, breaking anything that subclasses urllib3 internals
# (docker-py/testcontainers on Windows: "NpipeHTTPConnectionPool._get_conn()
# got an unexpected keyword argument 'heb_timeout'"). Building it from sdist
# with URLLIB3_NO_OVERRIDE=1 in the environment is the maintainer-documented
# opt-out: both namespaces then coexist (urllib3 genuine, urllib3_future fork)
# and niquests falls back to urllib3_future automatically. Every installer of
# the lockfiles must therefore export URLLIB3_NO_OVERRIDE=1 (Taskfile setup,
# Dockerfiles, CI). Guard: tests/unit/test_urllib3_namespace_guard.py.
